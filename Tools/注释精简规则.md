# 注释精简：风格与判据（本仓专用）

目标：**只压注释，代码一个字节都不许动。** 全仓注释占比要从 ~31% 降到 15% 以下。
分配给你的一批文件，目标是把**该批注释行数压到总行数的 10% 以下**。

## 第一性判据（每一次删除都问这一句）

> 这条注释是不是在防止某个人做出一个「**编译器不会拦、测试不会红、只表现为手感/观感错**」的改动？

- 是 → **留**（压成 1–3 行短句）。
- 否 → **删**。

## 优先删（本仓最大的噪音）

1. **变更史与自我辩护**：`收口前…`、`旧实现…`、`早期曾…`、`（审查已定…）`、`（评审：…）`、
   `<b>不是</b>无意义转发`、`刻意…`、`理由：…`、`当时的理由…`、`查过全库`、`首推者预计…`。→ 全删。
2. **以"为什么当初这样写"开头的长 `<remarks>`**：整块删。保留 `<inheritdoc />`。
3. **复述代码的 `<param>` / `<returns>` / `<summary>`**：参数名已说明一切的 `<param name="row">表行</param>` → 删。
   挂在 `public float Now => _now;` 上、正文只有"本步的逻辑时刻（秒）"的 `<summary>` → 删或留 3 个字。
4. **多行 `<summary>` 里的散文**：只留可判定契约（数值口径 / 单位 / 边界条件 / 非法值兜底 / 静默失败）。
   形容词堆砌、`<b>` 强调、"这条不变量是…的实现形态" → 删。
5. **`<para>` 堆砌的"为什么不那样写"**：列举未采纳方案及其缺陷的 → 删。
6. **同一段帧序/分工说明在多文件重复**：只在最上游那个类留一份，其余改成一句
   `帧序见 ActorLogic`（或对应的上游类名）。
7. **纯装饰分隔注释**：
   ```
   // ─────────────────────────────────────────────
   // IActorLedger：读
   // ─────────────────────────────────────────────
   ```
   上下两条横线 → 删；中间那行**有信息**（分区名）可留成一行 `// IActorLedger：读`。
8. **私有成员上复述代码的注释**：`// 没有期望方向：把速度指数收缩到零。` 这类，
   但**"静默失败 / 不报错 / 看起来正常"型**的要留。

## 必须留（本仓注释的唯一价值所在）

- 任何写着 **"不报错" / "静默" / "看起来一切正常" / "不会红"** 的段落。
- **数值口径 / 单位 / 边界条件 / 非法值兜底**（NaN、负数、`≤ 0` 表示什么、`0` 表示什么）。
- **帧序与唯一调用方**（谁在帧首清、谁在帧末写、只能从哪调）。
- **一次性 vs 持久**（"帧首复位，必须每帧重新提交"这类）。
- 任务书里点名给你的**受保护事实**（每批单列）。这些事实**只存在于注释里**，
  删掉就永久丢失 —— 要求：**原意不动，压成 1–3 行短句**，并允许改写措辞使其更紧凑。

## 硬规矩

- **不许改任何代码 token**，包括空格与换行位置。只删/改注释行与注释块。
- **不许改 XML 标签语法**：`/// <summary>`、`/// <remarks>`、`/// <inheritdoc />`、`<para>`、`<see cref="…"/>`
  的写法保持原样；整块 `<remarks>…</remarks>` 可以整体删除。
- **不许动 `#region` / `#endregion`、预处理指令、`using`。**
- **不许改文件行尾风格**（有的文件 CRLF、有的 LF；编辑工具会保留，别用脚本统一重写）。
- **不许合并成一段长句**：短句、分点、每点一行。
- 中文保持中文。
- 只改分配给你的文件，**碰别人的文件**（含 `Assets/Tests/**`、`Generated/**`、`Luban.Runtime/**`）会冲突。

## 自查（必做，改完立刻跑）

```powershell
pwsh -NoProfile -File Tools/comment-verify.ps1 -BaselineDir "$env:TEMP\ds_snap0" -Files "<你的文件1;文件2;...>"
```
必须输出 `PASS: 所有被检查文件的非注释行逐行未变`。
它会逐行比对"改前快照"与"当前文件"的**非注释行序列**（注释行 = `TrimStart()` 以 `//` `/*` `*` 开头）。
出现 `VIOLATIONS` 就是**你改动了代码**，立刻改回去。

再看占比：
```powershell
pwsh -NoProfile -File Tools/comment-stat.ps1 | Select-String "你的文件名"
```
输出格式 `路径|总行数|注释行|占比|空行`。

## 交付（回给上级的文字）

1. 逐文件：`改前注释/占比 → 改后注释/占比`。
2. `comment-verify` 的 PASS 行原文。
3. **⚠️ 事实交接清单**：你删掉的注释里，任何"值得留在项目文档里的事实"（某成员零消费者、
   某处标着"将来会做"、某个数值口径的来源、某个只在这里写过的约定）。
   **逐条列出并附它原来所在的 `文件:行`。宁可多列。** 这份清单会交给下一个做文档整理的 Agent。
