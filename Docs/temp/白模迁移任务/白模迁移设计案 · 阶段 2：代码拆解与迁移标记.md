**`TakeDamage` 重构**：

```
旧：TakeDamage(in Damage) + TakeDirectDamage(int)
新：TakeDamage(in Damage)
    - Damage 携带 Amount / Point / 可选 Impulse / Source
    - 击退可选：Impulse == 0 时不击退
    - 去重逻辑：球 ID 不再用于去重（球不再伤害敌人）；改为"格子结算 ID"
```

### 2.4 格子系统

#### `TileLogic.cs`

| 项       | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 类型     | `MonoBehaviour`                                              |
| 迁移性质 | **拆分（5 路）**                                             |
| 目标 A   | `Logic/Grid/GridLogic.cs`（格子状态持有者 + Tick 调度 + 联动发起） |
| 目标 B   | `Logic/Grid/TileStateMachine.cs`（格子状态机）               |
| 目标 C   | `Logic/Grid/ITileState.cs` + 各状态实现（本次只做泥浆）      |
| 目标 D   | `Logic/Grid/TileTickQueue.cs`（双缓冲队列）                  |
| 目标 E   | `Presentation/Grid/GridView.cs` + `TileEffectView.cs`（Tilemap 视觉 + 瞄准高亮） |
| 目标 F   | Logic 层的 `TileAim.cs`（`TryGetAimPoint` 吸附计算）         |
| 目标 G   | `Logic/Grid/EnemyCellRegistry.cs`（敌人归属映射）            |

**关键改造**：

| 白模方法                  | 迁移去向                              | 改造                           |
| ------------------------- | ------------------------------------- | ------------------------------ |
| `OnBallHit`               | `GridLogic.OnBallHit(cell, ballType)` | 球不再造成伤害，只触发状态转换 |
| `DamageEnemiesOnTile`     | **删除**                              | 由状态转换的基础伤害接管       |
| `RestoreTile` 协程        | `TileStateMachine` 计时               | 暂用协程，等时间轮             |
| `GetSlowMultiplier`       | `GridLogic.GetSlow(cell)`             | 保持                           |
| `WorldToCell`             | `GridLogic.WorldToCell`               | 保持                           |
| `SetAimCell` / `ClearAim` | `TileEffectView`                      | 视觉层                         |
| `TryGetAimPoint`          | `Logic/Grid/TileAim.cs`               | 纯函数                         |

**新增的通用逻辑**（白模没有的）：

- `TileStateMachine`：状态 `OnEnter` / `OnTick` / `OnExit` 钩子
- `TileTickQueue`：双缓冲
- `Linkage` 双通知
- 联动计数
- 空间查询接口
- 状态转换即基础伤害
- 格子初始状态从 Luban 加载
