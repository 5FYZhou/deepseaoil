# 《美术装配指南》

---

### 一、切图与导入规范（硬性）

1. **导入参数**：
   - **PPU (Pixels Per Unit)**：必须设为 **`128`**（严格对齐 128×128 瓦片尺寸）。
   - **Filter Mode**：像素画选 `Point`；手绘/矢量选 `Bilinear`。
   - **Compression**：选 `None` 或 `Normal Quality`。
2. **Pivot 对齐约束**：
   - **角色与贴地道具**：必须设为 **`Bottom (X: 0.5, Y: 0.0)`**（防止 Y-Sort 排序闪烁与脚底悬空）。
   - **地块瓦片与 UI**：设为默认 `Center (0.5, 0.5)`。

---

### 二、地块 TileBase 归档规约（约定懒加载）

- **归档路径**：必须放入 **`Assets/Resources/tiles/`** 目录。
- **文件命名**：必须严格命名为 **`Tile_<TileStateType 枚举名>.asset`**。

#### 19 种合法地块文件名速查（直接复制命名）：
```text
Tile_Normal.asset               Tile_Mud.asset                  Tile_MudSkid.asset
Tile_Smoothie.asset             Tile_Freeze.asset               Tile_TerracottaBrick.asset
Tile_FrozenEarth.asset          Tile_Steam.asset                Tile_ConductElectricity.asset
Tile_Vine.asset                 Tile_Glass.asset                Tile_Burn.asset
Tile_Ashes.asset                Tile_BasicWater.asset           Tile_BasicEarth.asset
Tile_BasicFire.asset            Tile_BasicIce.asset             Tile_BasicElectricity.asset
Tile_BasicPlant.asset
```
> *规则*：只要文件名对，程序 `AssetModule.Load` 运行时自动按需寻址，无需在场景 Inspector 中连线。
> *同时*：InitialSetup 层上的笔刷贴图也按这个名字反查地块状态（先认 `Tile_<枚举名>`，再认资产自带的 `<枚举名>`），所以命名对了两处都免接线。

### 三、场景 Tilemap 三层装配标准

在场景的 `Grid`（Cell Size = 1, 1, 0）节点下保持三层结构：

```text
Grid
├── Ground          (TilemapRenderer Order = 0)  ← 地板层（必须刷满常规地板，提供合法走行动线）
├── InitialSetup    (TilemapRenderer Order = 1)  ← 关卡编辑层（用笔刷在此画开局火池/冰面/植物，启动后自动读取并隐藏）
└── TileEffect      (TilemapRenderer Order = 2)  ← 动态反应层（运行时状态覆盖层，开局留空）
```

- **`TilemapAdapter` 接线**：
  - `groundTilemap` 拖入 `Ground`。
  - `effectTilemap` 拖入 `TileEffect`。
  - `initialSetupTilemap` 拖入 `InitialSetup`。
  - `stateTiles` 数组**保持为空**（自动走约定的 `tiles/Tile_*.asset`）。

### 四、角色 Animator 控制器快速构建（3 步）

1. **建立剪辑**：
   - 切片拖入生成 `Player_Idle.anim`（采样率 12，Loop Time 勾选）。
   - 切片拖入生成 `Player_Walk.anim`（采样率 12~15，Loop Time 勾选）。
2. **状态机配置**：
   - 新建 `PlayerAnimator.controller`，添加 Float 参数：**`Speed`**。
   - `Idle` ➔ `Walk`：条件 `Speed > 0.01`，**取消勾选 `Has Exit Time`**，`Transition Duration = 0`。
   - `Walk` ➔ `Idle`：条件 `Speed < 0.01`，**取消勾选 `Has Exit Time`**，`Transition Duration = 0`。
3. **挂载**：
   - 挂载 `PlayerAnimationView` 与 `Animator` 至 Player 根节点，指定该 Controller。
