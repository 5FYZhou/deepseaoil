## 1. 它原来做什么

`AggroState` 是敌人唯一的「是否已锁定玩家」裁决者，每个物理帧由 `EnemyLogic.Tick` 推进一次，输出布尔 `HasAggro`。下游只有一处消费：`ChaseBrain.Decide` 里的 `if (!ctx.HasTarget || !ctx.HasAggro) return EnemyIntent.Idle;` —— 没仇恨就站着不动，有仇恨才 `Steering.Resolve` 追。

三个参数全部来自调参 SO，不入表：`EnemySpec.VisionRange / SustainRange / LoseDelay` → `EnemyTuningEntry.visionRange / sustainRange / loseDelay` → 构造函数注入。

| 参数 | 单位 | 原语义 |
| --- | --- | --- |
| `visionRange` | 世界单位 | **获得**仇恨的视野半径。用平方距离比较（`sqrDist <= visionRange²`），进圈即 `_hasAggro = true` 并刷新 `_lastSeenTime` |
| `sustainRange` | 世界单位 | **维持**仇恨的半径。已锁定后，即使在视野外，只要还在维持圈内就刷新 `_lastSeenTime`。配表惯例 `sustainRange > visionRange`，故意做出迟滞（hysteresis），防止玩家卡在视野边缘时敌人反复进出追击/停手 |
| `loseDelay` | 秒 | **脱战**延迟。既出视野又出维持圈后开始计时，`now - _lastSeenTime >= loseDelay` 才真正清仇恨。玩家绕柱、短暂脱离不会立刻脱战 |

`Tick` 的判定顺序（顺序本身就是设计，不能调换）：

1. `target` 为空 → **直接 return，不衰减任何计时**（保持现状）；
2. 消费白雾抑制窗（见 §3）；
3. 视野内且过了抑制窗 → 获仇并刷新时间戳；
4. 尚未获仇 → 退出（无处可丢）；
5. 维持圈内 → 只刷新时间戳，继续保持；
6. 出两圈且超时 → 清仇恨。

⚠️ **已知反直觉行为（刻意设计，不是 bug）**：第 1 条让「目标消失」（玩家死亡、未生成、`SetTarget(null)`）时仇恨**保持不动**，敌人会继续按上一帧的仇恨状态行动，而不是按 `loseDelay` 脱战。原逻辑靠 `EnemyLogic` 侧的对象生命周期兜底，`AggroState` 自身不做失效判定。

## 2. 白雾抑制逻辑（本次下线后失效的那部分）

`ForceLose()` 走的是「清仇恨 + 开抑制窗」两条：

```csharp
public void ForceLose()
{
    _hasAggro = false;      // 当场清
    _suppressAgro = true;   // 并挂起一个抑制请求
}
```

真正的抑制落在下一帧 `Tick` 的头部：把 `_hasAggro` 再压一次，并写 `_suppressUntil = now + _loseDelay`；而视野判定带条件 `now >= _suppressUntil`，于是**白雾后的 `loseDelay` 秒内，哪怕玩家就站在敌人视野正中，也重新拿不到仇恨**。

这个抑制窗不是冗余：只把 `_hasAggro` 置 `false` 而不带窗，敌人下一帧就会因为「玩家在视野内」立刻重新锁定，白雾的 `break_aggro = True` 在手感上等于没发生。原注释「清仇恨抑制窗，删了白雾只生效 1 帧」说的就是这件事。

调用方：`ConfigModule.GetDuoReactions()` → `DuoReactionCatalog` → `TileChainReactor.TriggerDuo` → `CommitDuo` → `BreakAggroInRadius`（`element_duo_reaction.break_aggro = True`，当前只有白雾 id 5 填 True）→ `IAggroBreakable.ForceLoseAggro()` → `EnemyActor.ForceLoseAggro()` → `EnemyLogic.ForceLoseAggro()` → `AggroState.ForceLose()`。

**下线后的现状**：这条链的每一环仍然存在（因此不存在编译断链），但 `EnemyLogic.ForceLoseAggro()` 已是空实现，白雾现在只剩「铺空地 + 向心吸力」两个效果，「清仇恨」语义消失。

## 4. 原始源码（逐字存档）

```csharp
using UnityEngine;

namespace DeepseaOil.Logic
{
    /// <summary>仇恨状态：视野内获得、维持距离内保持、超时丢失</summary>
    public sealed class AggroState
    {
        private readonly float _visionRange;

        private readonly float _sustainRange;

        private readonly float _loseDelay;

        private bool _hasAggro;
        private float _lastSeenTime;

        /// <summary>清仇恨抑制窗，删了白雾只生效 1 帧</summary>
        private bool _suppressAgro;

        private float _suppressUntil;

        public AggroState(float visionRange, float sustainRange, float loseDelay)
        {
            _visionRange = visionRange;
            _sustainRange = sustainRange;
            _loseDelay = loseDelay;
        }

        public bool HasAggro => _hasAggro;

        /// <summary>每物理帧调；target 为空时保持现状</summary>
        public void Tick(Vector2 self, Vector2? target, float now)
        {
            if (!target.HasValue) return;

            if (_suppressAgro)
            {
                _suppressAgro = false;
                _hasAggro = false;
                _suppressUntil = now + _loseDelay;
            }

            float sqrDist = (target.Value - self).sqrMagnitude;

            if (sqrDist <= _visionRange * _visionRange && now >= _suppressUntil)
            {
                _hasAggro = true;
                _lastSeenTime = now;
                return;
            }

            if (!_hasAggro) return;

            if (sqrDist <= _sustainRange * _sustainRange)
            {
                _lastSeenTime = now;
                return;
            }

            if (now - _lastSeenTime >= _loseDelay) _hasAggro = false;
        }

        /// <summary>强制清仇恨，供 IAggroBreakable 用</summary>
        public void ForceLose()
        {
            _hasAggro = false;
            _suppressAgro = true;
        }
    }
}
```
