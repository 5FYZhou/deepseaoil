# 敌人仇恨系统 · 已移除

> 状态：**已下线**。源码 `AggroState` 已物理删除（含 `.meta`），全仓零引用（`AggroState` 这个名字现在只出现在本文件与本文件的历史提交里）。
> 本文只保留**今天仍然成立的事实**：哪些契约还在、现行为是什么、要恢复得动哪些地方。
> 逐字源码与逐参数语义**不再留档** —— 需要时从 Git 取（见 §3）。

## 1 · 下线范围与留下的东西

只删「视野获仇 / 维持 / 超时脱战」这一套状态机。**下面这些刻意保留**：

- **`IAggroBreakable` 接口**（`Assets/Scripts/Logic/Combat/IAggroBreakable.cs`）：调用链
  `ConfigModule.GetDuoReactions()` → `DuoReactionCatalog` → `TileChainReactor.TriggerDuo` → `CommitDuo`
  → `BreakAggroInRadius`（`element_duo_reaction.break_aggro = True`）→ `IAggroBreakable.ForceLoseAggro()`
  **每一环都还在，因此不存在编译断链**。
- **`EnemyActor.ForceLoseAggro()` / `EnemyLogic.ForceLoseAggro()`**：签名保留，**方法体已是空实现**。
- **`EnemyTuningEntry` 的四个历史字段**（`chaseRange` / `visionRange` / `sustainRange` / `loseDelay`）：
  声明与默认值原样保留（不破坏 `Resources/tuning/EnemyTuning.asset` 的序列化），`[Tooltip]` 已标注退役。

> ⚠️ **净效果**：敌人在拿到 Target 之后**全速直追、没有追逐距离上限**（原「跑得够远能脱离」的设计随之取消）；
> `Steering.Resolve` 里唯一剩下的距离判据是 `stopDistance`（贴脸停住）。
> `Steering.Resolve` 已**删除** `chaseRange` 形参与 `distance > chaseRange → default` 判据。

**当前的实际后果**：白雾（`break_aggro`）现在只剩「铺空地 + 向心吸力」两个效果，**「清仇恨」语义已消失** ——
`EnemyLogic.ForceLoseAggro()` 是 no-op，所以白雾炸在敌人脚下不会再让它停手。这是已知且接受的现状，
不是漏接线（链子在、只是末端空转）。

## 3 · 如果哪天要把仇恨做回来

- **原文件从 Git 历史取**：
  `git log --diff-filter=D -- Assets/Scripts/Logic/Actor/AggroState.cs` 找到删除提交，再
  `git checkout <删除前的提交> -- Assets/Scripts/Logic/Actor/AggroState.cs Assets/Scripts/Logic/Actor/AggroState.cs.meta`
  （`.meta` 的 guid 为 `86cf6c91f9fa0b64ebf06583b13d29a4`，删除前已确认无任何场景 / 预制体 / 资产序列化引用它）。
- **回补清单**：`EnemyLogic` 的字段与 `Tick` 推进、`ChaseBrain.Decide` 的 `!ctx.HasAggro` 判据、
  `EnemyLogic.ForceLoseAggro()` 的方法体、`EnemyBrainContext.HasAggro` 与构造参数、`EnemySpec` 的四个属性，
  以及 `Steering.Resolve` 的 `chaseRange` 形参与判据 —— **想恢复「跑远能脱离」，最后这一处必须一并回补**，
  否则追逐仍然是全图的。
- **参数不用重新配表**：`chaseRange` / `visionRange` / `sustainRange` / `loseDelay` 仍在
  `Resources/tuning/EnemyTuning.asset` 里躺着（`[Tooltip]` 已标注退役），改回被读即可。
- **两处设计细节，恢复时别丢**（原实现里顺序本身就是设计）：
  ① `target` 为空时**直接 return、不衰减任何计时**（保持现状，而不是按 `loseDelay` 脱战）；
  ② `ForceLose()` 走「清仇恨 + 开抑制窗」两条 —— 只把 `_hasAggro` 置 `false` 而不带窗，
  敌人下一帧就会因为「玩家在视野内」立刻重新锁定，**白雾的 `break_aggro = True` 在手感上等于没发生**。
