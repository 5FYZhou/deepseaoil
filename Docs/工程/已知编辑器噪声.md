# 已知编辑器噪声

> 这里记的是**只在 Unity 编辑器里出现、打包产物里不存在**的报错与警告。
>
> **判据**：报错栈里有编辑器专有帧（`GUIUtility:ProcessEvent` / `EditorGUI` / `Handles` 等），
> 且**没有任何本工程脚本的帧**。命中判据 = 不是游戏 bug，**不要为它改代码**。
>
> 文档是快照不是契约：与代码冲突时以代码为准。

## 一 · `RendererUpdateManager.UpdateAll must be called first`

| 项 | 内容 |
| :-- | :-- |
| 原文 | `In order to call GetTransformInfoExpectUpToDate, RendererUpdateManager.UpdateAll must be called first.` |
| 栈 | `UnityEngine.GUIUtility:ProcessEvent (int,intptr,bool&)` —— **只有这一帧** |
| 现象 | 点 Play 立刻红字一条；与鼠标/输入无关，不是每帧刷 |
| 属性 | **噪声**：编辑器专有路径，打包产物里不存在这条栈 |
| 记录于 | Unity 2022.3.62，合并 `upstream/main`（`35f6b38`）之后 |

**判定依据**：栈里只有编辑器 IMGUI 事件泵一帧，没有任何本工程脚本的帧。
若触发者是 `MonoBehaviour` 回调（`OnGUI` / `OnDrawGizmos` / `OnValidate`），Unity 必然在栈里列出那个方法。
据此**已排除** `PolygonRaycastSettings.OnDrawGizmos` —— 该组件 `showPreview` 默认关闭，方法第一行就 `return`，
根本读不到 Transform。

**成因**：URP 2D 的 `RendererUpdateManager` 在进入 Play 的第一帧还没执行 `UpdateAll`，
而编辑器因模式切换抢先重绘了 Scene 视图 / IMGUI，重绘路径里向某个对象要了 Transform 信息 → 断言报一次。
官方同族条目（同一断言的不同触发点）：

- [进入 Play 模式时抛出](https://issuetracker.unity.com/issues/8188/rendererupdatemanagerupdateall-must-be-called-first-error-is-thrown-when-entering-the-play-mode)
- [添加 RectTransform 时](https://issuetracker-mig.prd.it.unity3d.com/issues/in-order-to-call-gettransforminfoexpectuptodate-rendererupdatemanager-dot-updateall-must-be-called-first-when-adding-recttransform)
- [Scene 视图选中「RectTransform ＋ 被关闭的 SpriteRenderer」时](https://issuetracker-mig.prd.it.unity3d.com/issues/renderupdatemanager-asserts-when-selecting-an-object-with-a-rect-transform-and-a-disabled-sprite-renderer-in-the-scene-view)
- [CommandBuffer.DrawRenderer 打到被关闭的 MeshRenderer 时](https://issuetracker-mig.prd.it.unity3d.com/issues/assertion-failed-rendererupdatemanager-when-calling-commandbuffer-dot-drawrenderer-on-disabled-mesh-renderer)

**处置**：**不改代码**。想让它彻底闭嘴只有两条路 —— 升级 Unity 补丁版；
或清掉场景里「RectTransform 上挂着被禁用的 SpriteRenderer」这类组合。

## 二 · `UnityEditor.Graphs.Edge.WakeUp` 空引用（每次域重载一条）

| 项 | 内容 |
| :-- | :-- |
| 原文 | `NullReferenceException: Object reference not set to an instance of an object` |
| 栈 | `UnityEditor.Graphs.Edge.WakeUp` ← `Graph.DoWakeUpEdges` ← `Graph.WakeUpEdges` ← `Graph.WakeUp` ← `Graph.OnEnable` —— **全是 `UnityEditor.Graphs` 的帧**（`UnityEditor.Graphs.dll`，编辑器自带） |
| 现象 | 每次 `Begin MonoManager ReloadAssembly`（重编译 / 进 Play / 载场景）刷一条；本机 `Editor.log` 里 18 次全部紧跟域重载 |
| 属性 | **噪声**：`Assets/**` 零引用 `UnityEditor.Graphs`，栈里没有任何本工程脚本的帧 |
| 记录于 | Unity 2022.3.62f3c1 |

**成因**：`Graph` 是 ScriptableObject，域重载时被 `OnEnable` 唤醒，遍历边时踩空。它归**编辑器布局里那个 Animator 窗口**所有（`UserSettings/Layouts/default-2022.dwlt`，gitignore 的本地件），窗口在布局里一天，每次重载就重建一次。
已排除的嫌疑：工程里 7 个 `Animator` 组件的 `m_Controller`、6 个 controller 内的全部剪辑引用与转移落点**都通**（无断链、无空落点转移），工程里也没装任何第三方图框架。

**处置**：**不改代码**。实测**重启 Unity 即可**（编辑器内存里的旧图状态随之清掉；这是 Unity 侧的历史遗留问题）。若重启后又回来再往上加码：① 右键 Animator 标签页 ▸ `Close Tab`，**然后** `Window ▸ Layouts ▸ Save Layout…` 覆盖当前布局 —— 只关标签页不落盘，布局一重载它又回来；② 或关掉 Unity 后把 `UserSettings/Layouts/*.dwlt` 改名/删除，下次启动即出厂布局。官方同族条目：[Animator 开着进 Play 报 Removing null node](https://issuetracker-mig.prd.it.unity3d.com/issues/getting-error-removing-null-node-when-entering-play-mode-while-animator-is-open-slash-visible-on-screen)、[空 Animator 窗口里点击报错](https://issuetracker-mig.prd.it.unity3d.com/issues/anim-error-clicking-in-empty-animator-window)。
