# 新场景接线

## 必备 / 禁止
- 场景需：`GameRoot`、`InputProvider`、`PlayerController`、`CombatRoot`、`TilemapAdapter`、有地板的 Tilemap、主相机。
- 禁止：`Canvas`、`EventSystem`、第二个 `AudioListener`。UI 由 `UIMgr` 自动创建。
- 敌人**两条路都行**：运行时按波次生成（默认），或直接在场景里摆 `Enemy_<id>` 预制体实例 —— `CombatRoot.AdoptSceneEnemy` 会自动收养，不必手工登记。
- 参考现状：主场景 `Assets/Scenes/Range.unity` = `GameRoot` ＋ `InputProvider` ＋ `TilemapAdapter` ＋ `BoundsArea` ＋ 六层 Tilemap（`Ground` ＋ `InitialSetup` ＋ 四个效果层 `TileEffect_Static` / `TileEffect_Fire` / `TileEffect_Water` / `TileEffect_Steam`），`CombatRoot` 是**场景组件**（`scane_prebs/` 里没有它的预制体），再摆 `Player` / `Virtual Camera` 预制体实例与 `Fountains` 下三个 `Fountain`（`kind` 0/1/2），外加一个手摆的 `Enemy_1`。

## 1. 场景
- 从 `Assets/Settings/Scenes/URP2DSceneTemplate.unity` 另存。
- **不加光源也能正常出图**（`Range.unity` 就没有任何光源；三个 `Slice_*` 沙盒里各有一个空物体叫 `Global Light 2D`，但都没有挂 `Light2D` 组件）。真出现精灵发黑时再加一盏 `Global Light 2D`。

## 2. Tilemap
- 建 `Grid`，子物体：`Ground` ＋ 效果层 `TileEffect_Static` / `TileEffect_Fire` / `TileEffect_Water` / `TileEffect_Steam`（按状态分组，每层一张 Tilemap、一个材质），`InitialSetup` 可选。
- `Ground` 刷 `Tile_Floor`，至少一格。
- `Sorting Order`：`Ground=0`，其余"越压上越大"。`Range.unity` = `InitialSetup 1` / `Static 2` / `Fire 3` / `Water 4` / `Steam 5`；三个沙盒都没有 `InitialSetup` 层，效果层 = `Static 1` / `Fire 2` / `Water 3` / `Steam 4`。
- `InitialSetup` 可选；不画也行。**不建这一层就把 `initialSetupTilemap` 留空**（三个沙盒的 `initialSetupTilemap` 都是 `{fileID: 0}`，也都没有该层）；建了就必须接进去。

## 3. GridView
新建空物体（现网场景里叫 `TilemapAdapter`），挂 `TilemapAdapter`：
- `groundTilemap` → Ground（必接）
- `effectLayers`：每行一个 `Tilemap` ＋ 该层负责的 `States`（同一状态只能登记在一层；一层都不接时状态只记逻辑、不显示）
- `fallbackEffectTilemap`：没在任何 `effectLayers` 行登记的状态落到这一层，留空 = 取 `effectLayers[0]`
- `initialSetupTilemap` → InitialSetup（可选）
- `stateTiles`：**保持空数组**（`Range` / `Slice_CombatSandbox` / `Slice_GridReaction` 三个接了 `TilemapAdapter` 的场景现在全是 `stateTiles: []`），状态贴图自动走约定路径 `Assets/Resources/tiles/Tile_<TileStateType 成员名>.asset`（**顶层，别建子目录**）
- `effectLayers` 的任一行都不能指向 `groundTilemap` / `initialSetupTilemap`，`fallbackEffectTilemap` 同理 —— 这三条在 `Awake` / `OnValidate` 打 LogError。

## 4. BoundsArea（可选）
- `BoxCollider2D`：`Is Trigger ✓`，`Size` = 可走区域。

## 5. 玩家
层级：
```text
Player
└── View
```

`Player` 根：
- `Rigidbody2D`：Gravity Scale 0；Freeze Rotation Z；Interpolate；Collision Detection = `Continuous`（`Player.prefab` 与 `Enemy_1.prefab` 现在都是 `Continuous`，见《美术装配指南》§5.1）
- `BoxCollider2D`：Size (0.7, 0.7)，非 Trigger
- `PlayerMotor`：`body` 留空
- `PlayerController`：`motor` = 自身 PlayerMotor；`inputProvider` = InputProvider；`aimCamera` 可空；`boundsArea` = BoundsArea；`animView` = View 上的 ActorAnimationView

`View`：
- `localPosition` / Rotation 归零
- `SpriteRenderer`：任意色块
- `Animator`：可留空
- `ActorAnimationView`：`animator` / `spriteRenderer` 可留空；`useFlipX` 不勾
- `SpriteRenderer` 必须挂 `View`，不能挂 `Player` 根。

## 6. InputProvider 与 GameRoot
各建空物体，分别挂 `InputProvider`、`GameRoot`，无字段。

## 7. CombatRoot 与 Fountain
`CombatRoot`：
- `player` = PlayerController（必接）
- `gridView` = TilemapAdapter（必接）
- `ballRoot` / `actorRoot` / `fountains` 可空
- `enableWaves ✓`

`Fountain`：
- `CircleCollider2D`：`Is Trigger ✓`，Radius 3
- `spawnInterval` 1
- `landingRadius` 3 / `minLandingDistance` 0.8

## 8. Cinemachine（可选）
- 主相机加 `Cinemachine Brain`；建 `2D Camera`。
- vcam：`Follow` = Player 根；`Look At` 空；`Orthographic Size` 8；`Camera Distance` 10；`Damping` 0.15~0.3；`Aim` = Do nothing；Brain `Update Method` = SmartUpdate。
- 可选：`CinemachineConfiner`，`Confine2D`，`Bounding Shape 2D` = BoundsArea，`Confine Screen Edges ✓`。

## 启动验收
Play 后 Console 应该**没有红色 `LogError`**（本工程没有"装配成功"日志）：
```text
（装配正常时 Console 干净；装配失败会打 `CombatRoot … 战斗内容已停用。` 之类的 LogError。）
```
- 菜单态点 `BeginPanel` 的 `StartBtn` 开始。
- WASD 移动、Shift 冲刺、左键水球、右键土球。
- 检查：Player 下只有 View 且 localPosition=(0,0,0)；Player 根无 SpriteRenderer / Animator；ActorAnimationView 在 View；`useFlipX` 未勾；相机 Follow 拖 Root；不加 `Global Light 2D` 也能出图（§1）；`effectLayers` 各行不指向 `groundTilemap` / `initialSetupTilemap`。
