# 光照与环境系统调参手册 (Lighting & Environment Tuning Manual)

> **生效效力**：本文为当前运行期状态快照。若与源码冲突，以源码为准，并同步修订本文。  
> **适用对象**：TA、关卡策划、环境美术、客户端程序。  
> **生效机制**：所有参数均为 `[SerializeField]` 字段或 Shader Properties。**改动无需编译、无需导表**，保存场景或材质资产即刻生效；PlayMode 下支持实时预览（退出运行态将还原，需在编辑态固化数值）。

## 二、A 区：TileGrid Lightmap（网格光场计算）

### 2.1 空间扩散与阴影

| 字段名                         | 脚本默认 |  场景推荐  |    有效区间    | 物理意义与调节指南                                           |
| :----------------------------- | :------: | :--------: | :------------: | :----------------------------------------------------------- |
| `airTransmission`              |   0.72   |  **0.80**  | `[0.50, 0.85]` | 空气透过率（光线跨单格保留率）。**光晕扩散范围总控制**。     |
| `obstacleTransmission`         |   0.20   |  **0.20**  | `[0.00, 0.40]` | 障碍物透过率。阻挡格光线穿透衰减率；数值越低，实体阴影越硬。 |
| `diagonalTransmissionExponent` |  1.4142  | **1.4142** | `[1.00, 2.00]` | 对角衰减指数（$\approx \sqrt{2}$）。**控制光场等值线圆润度**。 |

*   **`airTransmission` 衰减半径参照表（按能量衰减至 10% 测算）**：
    *   `0.72`：衰减半径 $\approx 7$ 格。光场紧凑，仅照亮核心发生区。
    *   `0.80`（基准）：衰减半径 $\approx 10$ 格。单片火源可覆盖小型战术厅堂。
    *   `0.85`：衰减半径 $\approx 14$ 格。大范围漫散，黑夜对比度被稀释。
*   **衰减模型关联性**：网格扩散与玩家随身光源共用该衰减速率（$- \log_2(\text{airTransmission})$），二者作用范围联动。
*   **对角指数约束**：严禁将 `diagonalTransmissionExponent` 设为 $\le 1.0$（退化为轴向十字）或接近 $0.707$（退化为 45° 曼哈顿菱形走样）。

### 2.2 火光呼吸调制 (Fire Breathing)

| 字段名            | 脚本默认 | 场景推荐 |    类型 / 范围    | 物理意义与调节指南                                           |
| :---------------- | :------: | :------: | :---------------: | :----------------------------------------------------------- |
| `fireBreathHertz` |   0.70   | **0.70** | `[0.10, 3.00]` Hz | 呼吸振荡频率。高于 1.5 Hz 会由“舒缓呼吸”异变为“故障频闪”。   |
| `fireBreathDepth` |   0.10   | **0.10** |  `[0.00, 0.40]`   | 摆动深度。光强在 $[\text{Base}-\text{Depth}, \text{Base}]$ 之间正弦波动。归零则恒定。 |
| `fireBreathBase`  |   1.00   | **1.00** |  `[0.60, 1.20]`   | 基准峰值强度。超过 1.0 会截断扩散曲线尾端，导致边缘显现菱形走样。 |
| `fireSourceColor` |    —     | **HDR**  |   `Color` (HDR)   | 火光核心色温。基准值：`(1.0, 0.549, 0.259)`。                |

### 2.3 电弧阶跃调制 (Electric Arc Jitter)

| 字段名                | 脚本默认 | 场景推荐 |   类型 / 范围    | 物理意义与调节指南                                           |
| :-------------------- | :------: | :------: | :--------------: | :----------------------------------------------------------- |
| `electricJitterHertz` |   18.0   | **18.0** | `[1.0, 40.0]` Hz | 抽搐阶跃频率。呈现硬阶跃高频抖动；低于 5 Hz 失去电弧质感。   |
| `electricPulseFloor`  |   0.85   | **0.85** |  `[0.00, 1.00]`  | 阶跃强度下限。                                               |
| `electricPulseDepth`  |   0.15   | **0.15** |  `[0.00, 0.50]`  | 阶跃振幅。$\text{Floor} + \text{Depth} > 1.0$ 时易导致局部过曝白化。 |
| `electricSourceColor` |    —     | **HDR**  |  `Color` (HDR)   | 电光核心色温（高压青白）。基准值：`(0.490, 0.976, 1.0)`。    |

### 2.4 随身光源 (Carry Light)

| 字段名                | 脚本默认 | 场景推荐 |  类型 / 范围   | 物理意义与调节指南                              |
| :-------------------- | :------: | :------: | :------------: | :---------------------------------------------- |
| `carryLightColor`     |    —     | **HDR**  | `Color` (HDR)  | 玩家脚底微光色温。基准值：`(1.0, 0.86, 0.66)`。 |
| `carryLightIntensity` |   0.50   | **0.50** | `[0.00, 1.00]` | 随身光峰值强度。设为 0 即完全闭合。             |

*   **特性**：以世界空间坐标做亚像素平滑跟随；为保持性能，随身光源不参与物理墙体遮挡计算。

## 三、B 区：Environment Director（时段与环境主光）

### 3.1 核心配置与时段系统

| 字段名                     |    默认值    |       范围       | 说明                                                   |
| :------------------------- | :----------: | :--------------: | :----------------------------------------------------- |
| `globalLight`              |   自动绑定   |        —         | 场景主 `Light2D` 组件引用。                            |
| `initialTimeOfDay`         |    `Day`     |       枚举       | 关卡初始化时段。切换至 `Night` 时全局主光压制至 0.20。 |
| `transitionDuration`       |    1.50 s    | `[0.10, 10.0]` s | 昼夜变换平滑插值时长。                                 |
| `customTimeOfDayOverrides` | `Length = 0` |       数组       | 自定义时段覆盖矩阵（优先级高于内置默认表）。           |

#### 内置时段基准参数 (TimeOfDaySetting)

| 时段枚举         | `LightColor` (HEX) | `Intensity` | `AmbientFloorColor` | 视觉指向                              |
| :--------------- | :----------------: | :---------: | :-----------------: | :------------------------------------ |
| **Day (白昼)**   |     `#FFFBF0`      |  **0.98**   |      `#595959`      | 纯净日光，保证手绘原画色相 1:1 还原。 |
| **Dusk (黄昏)**  |     `#F8B394`      |  **0.62**   |      `#3A2A38`      | 暖粉橘色，形成复古朋克反差感。        |
| **Night (夜晚)** |     `#7A75A0`      |  **0.20**   |      `#12101F`      | 冷蓝灰暗夜帷幕，确立极限高反差基底。  |

### 3.2 自定义时段覆盖使用规范
1. 在 `Custom Time Of Day Overrides` 数组中添加元素。
2. 选定目标 `Kind`，配置对应的 `Light Color` 与 `Intensity`。
3. **覆盖规则**：
   * 采用“整体结构覆盖”而非字段合并；同枚举项仅首条配置生效。
   * **安全防线**：新增元素默认 Alpha 为 0，组件将报错并自动丢弃未指定颜色的全黑配置。
   * 夜间 `Intensity` 不建议低于 **0.15**，否则将导致非受光区结构轮廓完全不可读。

## 六、调参故障与失效排查矩阵

| 现象 / 预期行为                               | 核心原因诊断                   | 标准处置流程                                       |
| :-------------------------------------------- | :----------------------------- | :------------------------------------------------- |
| 调整 `AmbientFloorColor` 无反应               | 该字段当前未接入渲染管线。     | 调整目标材质上的 `_AmbientFloor` 属性。            |
| 修改 `_Rim*` 或 `_Metal*` 画面无变化          | 前置功能总开关未启用。         | 确认 `_EnableRim = 1` 或 `_MetalIntensity > 0`。   |
| 直接修改 `Global Light 2D` 数值被复原         | 组件参数被每帧生命周期覆盖。   | 前往 B 区配置 `Custom Time Of Day Overrides`。     |
| 将 `_TileLightmap` 暴露为材质属性导致全屏黑斑 | 全局纹理命名冲突覆盖。         | `_TileLightmap` 必须保持由 C# 注入全局着色器环境。 |
| 尝试在场景中挂载 `TileLightDirector`          | 拟真点光源与新范式网格场冲突。 | **严禁挂载**；动态光已全面由网格扩散接管。         |

## 八、管线验证与门禁标准

1. **自动化编译与静态门禁**（改动底层 C# 或 Shader 后强制执行）：
   ```powershell
   pwsh Tools/compile-gate.ps1   # 必须达成 0 Error(s), 0 Warning(s)
   pwsh Tools/comment-lint.ps1   # 必须通过预算合规检查 (Exit 0)
   ```
2. **PlayMode 视觉验收标准**：
   * **形态拓扑**：黑夜火池光晕边缘圆润饱满，无 45° 菱形走样，无临界点高频撕裂颤动。
   * **运动轨迹**：玩家移动时，随身微光以连续亚像素平滑推移，无网格跳帧。
   * **层级渲染**：实体（角色、怪物、道具）踏入火光区域正确接收染色，离场平滑归入夜色。
   * **反馈通道**：受击闪白优先级高于光场，触发时稳定输出纯白剪影（走 `_FlashAmount` 通道）。
3. **回归护栏**：
   * 基础默认参数变动受 `参数暴露_光照常数默认值必须与旧硬编码逐位对齐` 单元测试保护，杜绝无意识的视觉回归。

## 九、着色器色彩合成数学模型

```text
       ┌── envLight   = max(_ShapeLightTexture0, _AmbientFloor) ──── [暗夜帷幕基底]
       │
光强 ──┼── tileLight  = _TileLightmap × _TileLightBoost ──────────── [网格泛洪火场]
(Max)  │
       └── carryLight = _CarryLightColor × Falloff(dist) ─────────── [随身移动微光]
              │
              ▼
  最终输出 = (BaseColor × 光强) ＋ _EmissiveBoost ＋ Rim/Metal ＋ Flash
```

*   **合成法则**：采用通道**取大（Max）**而非加法（Add），杜绝光斑重叠处的过曝白化。
*   **保底机制**：`_AmbientFloor` 仅约束环境光通道；夜间必须处于低位（$\le 0.20$），方可建立暗夜深邃度，使火场释放极致高反差。
