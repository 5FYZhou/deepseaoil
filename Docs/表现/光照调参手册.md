# 光照调参手册

> 面向：想在 Inspector 里直接捏光照观感的人（策划 / 美术 / 程序）。
>
> **本文是快照不是契约**：与代码冲突以代码为准，并回头把本文改回来。
> 全部参数都是 `[SerializeField]` 字段或 Shader 属性 —— **改完不需要编译、不需要导表**，保存场景/材质即生效；
> PlayMode 中拖动滑杆**立即**看到结果（但退出 PlayMode 会回滚，想留住就在非运行态再填一次）。

## 一 · 面板地图：一共只有四处

| 序号 | 位置 | 管什么 |
| :-- | :-- | :-- |
| **A** | `Range.unity` ▸ `[Environment]` ▸ **TileGrid Lightmap** 组件 | 网格光场本体：扩散半径、墙体阴影、火光呼吸、电弧抽搐、随身光源 |
| **B** | `Range.unity` ▸ `[Environment]` ▸ **Environment Director** 组件 | 昼夜时段的全局光颜色 / 强度、过渡时长、时段覆盖 |
| **C** | `Assets/Resources/materials/M_CelLit_Default.mat` | 全工程默认受光材质（地面 / 角色 / 敌人 / 掉落物 / 场景道具） |
| **D** | `Assets/Resources/materials/M_TileFlow_{Fire,Water}.mat`、`M_TileFlow_Grass.mat` | 火场 / 水面 / 草丛三层的专用材质 |

> `[Environment]` 下还有一个子物体 **Global Light 2D** —— 那是 URP 的全局光，
> 它的 `Color` / `Intensity` **由 B 每帧覆写**，不要直接手改（改了会被冲掉）。
>
> 想验证某个参数属于哪一层：A/B 的值在**场景**里，C/D 的值在**材质**里。
> 场景改动随场景走，材质改动**全场景所有引用者一起变**。

## 二 · A 区：TileGrid Lightmap

### 2.1 扩散配置（决定光斑大小与阴影硬度）

| 字段名 | 脚本默认 | 场景现值 | 范围 | 含义 |
| :-- | :-- | :-- | :-- | :-- |
| `airTransmission` | 0.72 | **0.80** | 0.5 ~ 0.85 | 空气透过率：光每跨一格保留多少。**这是"光晕半径"的总开关** |
| `obstacleTransmission` | 0.20 | **0.20** | 0 ~ 0.4 | 墙体透过率：光穿过阻挡格剩多少。越小阴影越硬 |
| `diagonalTransmissionExponent` | √2 ≈ 1.4142 | 1.4142 | 1.0 ~ 2.0 | 对角衰减指数。**决定等值线圆不圆**，见下方警告 |

**`airTransmission` 的量感**（按"光强衰减到 10%"计算距离）：

| 取值 | 光晕半径 | 观感 |
| :-- | :-- | :-- |
| 0.72 | ≈ 7 格 | 紧凑，火光只照亮身边 |
| **0.80（当前）** | ≈ 10 格 | 一池火照出一个小厅 |
| 0.85 | ≈ 14 格 | 大范围泛光，夜色的"黑"被稀释 |

> ⚠️ **`airTransmission` 是同一条曲线的两个用途**：网格扩散与**随身光源**都用 `-log2(airTransmission)` 当每格衰减指数
> （片元里 `exp2(-距离 × 该指数)` 就是 `airTransmission^距离`）。
> 调小它 → 火光照得近 **且** 玩家脚下那圈也变小；调大 → 两者一起变大。不存在"只调其中一个"的旋钮。

> ⚠️ **不要为了"看起来更圆"把 `diagonalTransmissionExponent` 往下拉。**
> 该值必须 > 1 且接近 √2。压到 1.0 = 对角完全不吃惩罚，光斑会退化回十字/方形；
> 压到 0.707 附近会**让对角项弱于两格正交**，等值线直接变成 **45° 菱形** —— 那是本项目已经修掉的旧缺陷，别用手把它请回来。

### 2.2 火光呼吸

| 字段名 | 脚本默认 | 场景现值 | 范围 | 含义 |
| :-- | :-- | :-- | :-- | :-- |
| `fireBreathHertz` | 0.7 | **0.7** | 0.1 ~ 3 | 呼吸频率（Hz）。**超过 1.5Hz 就从"呼吸"变成"闪烁"** |
| `fireBreathDepth` | 0.10 | **0.10** | 0 ~ 0.4 | 呼吸摆幅。光强在 `base-depth` ~ `base` 之间正弦摆动 |
| `fireBreathBase` | 1.0 | 1.0 | 0.6 ~ 1.2 | 呼吸基准强度。与 depth 联手决定火光**平均亮度** |
| `fireSourceColor` | (1, 0.549, 0.259) | 同左 | HDR | 火光基色。偏红=岩浆，偏黄=篝火，提亮 >1 会更"烧" |

- 想让火**完全静止**：`fireBreathDepth = 0`。
- 想复刻旧点光时代的摆幅（0.88 ~ 1.00）：`fireBreathBase = 1.0`、`fireBreathDepth = 0.12`。
- `fireBreathBase` 调过 1.0 会把扩散的指数尾巴抬成平顶 —— **平顶的边界就是菱形**，慎调高。

### 2.3 电弧抽搐

| 字段名 | 脚本默认 | 场景现值 | 范围 | 含义 |
| :-- | :-- | :-- | :-- | :-- |
| `electricJitterHertz` | 18 | 18 | 1 ~ 40 | 阶跃频率（Hz）。电弧**本来就该抖**，压到 5 以下会变成呼吸 |
| `electricPulseFloor` | 0.85 | 0.85 | 0 ~ 1 | 电光强度下限 |
| `electricPulseDepth` | 0.15 | 0.15 | 0 ~ 0.5 | 每档跳变幅度（硬阶跃，不是正弦） |
| `electricSourceColor` | (0.490, 0.976, 1) | 同左 | HDR | 电光基色，青白 = 高压电弧 |

> ⚠️ `electricPulseFloor + electricPulseDepth` **超过 1 就会过曝到纯白**：电光会糊成一团白色，丢掉青蓝色相。

### 2.4 随身光源（玩家脚下那圈暖光）

| 字段名 | 脚本默认 | 场景现值 | 范围 | 含义 |
| :-- | :-- | :-- | :-- | :-- |
| `carryLightColor` | (1, 0.86, 0.66) | **同左** | HDR | 颜色决定暖度；调冷会像手电筒，调亮会盖掉火光 |
| `carryLightIntensity` | 0.5 | **0.5** | 0 ~ 1 | 峰值强度。**0 = 关闭**（玩家夜里只能看火光） |

- 衰减速率**没有独立旋钮**，它跟随 `airTransmission`（见 2.1 的警告）。
- 随身光是世界坐标连续推进的，走路时不会一格一跳；代价是它**不做墙体遮挡**（不会在墙角投出影子）。

> 📌 **"为什么 Inspector 里的值和我看到的默认值一模一样"**：本手册的"脚本默认"就是代码里的字段初值；
> 场景里尚未序列化的字段（如 `fireBreathBase`、`electricJitterHertz`、两个 HDR 色）会直接显示脚本默认值。
> 在编辑器里保存一次场景后，它们就会被写进 `.unity` 文件，"场景现值"一栏也就有了独立数值。

## 三 · B 区：Environment Director

| 字段名 | 脚本默认 | 场景现值 | 范围 | 含义 |
| :-- | :-- | :-- | :-- | :-- |
| `globalLight` | 空（自动抓子节点） | **已绑子节点** | — | 场景唯一的 Global Light 2D |
| `initialTimeOfDay` | Day | **Day** | 枚举 | 开局时段。改成 `Night` 后全局光被压到 0.20，只有火光/随身光照得亮 |
| `transitionDuration` | 1.5 | 1.5 | 0.1 ~ 10 | 时段过渡插值时长（秒）。0.1 会近似瞬跳 |
| `customTimeOfDayOverrides` | 空数组 | **空** | — | 时段覆盖表，见下 |

### 3.1 内置时段表（`TimeOfDaySetting.GetDefault`）

| 时段 | `LightColor` | `Intensity` | `AmbientFloorColor` |
| :-- | :-- | :-- | :-- |
| Day | `#FFFBF0` | 0.98 | `#595959` |
| Dusk | `#F8B394` | 0.62 | `#3A2A38` |
| Night | `#7A75A0` | **0.20** | `#12101F` |

这张表是**代码里的内置兜底**。想改而不改代码，用下面的覆盖数组。

### 3.2 用覆盖数组改昼夜（推荐）

1. `Custom Time Of Day Overrides` 点 `+` 添加一个元素；
2. `Kind` 选你要改的时段（`Day` / `Dusk` / `Night`）；
3. 直接填 `Light Color`、`Intensity`。

规则：

- **数组里没写的时段**继续用 §3.1 的内置值，不会被打乱。
- 同一 `Kind` 写多条，**只有第一条生效**。
- 覆盖的是**整个** `TimeOfDaySetting` 结构体，不是逐字段合并 —— 所以加一条 `Night` 覆盖时，`Light Color` 与 `Intensity` 都要照你的意图填好（不填就是 Inspector 显示的值）。
- 新加元素的默认色是 `(0,0,0,0)`：**忘了填 `Light Color` 会让那个时段的全局光变成纯黑**。
  为此组件带了一个保险 —— Console 会打印
  `[Light] 时段覆盖第 N 条的 Light Color 未填写（alpha=0）`，看到它就去补值。

| 想要的效果 | 怎么调 |
| :-- | :-- |
| 夜更黑、火光更炸 | `Night.Intensity` 0.20 → **0.15**（下限就是 0.15） |
| 夜晚更冷蓝 | `Night.LightColor` 往蓝紫偏 |
| 黄昏更橙、更亮 | `Dusk.LightColor` / `Intensity` |
| 切换变慢（过关演出感） | `transitionDuration` → 3 ~ 5 |

> ⚠️ `Intensity` 的 `Range` 下限是 **0.15**：低于它夜色会彻底黑掉、连地面轮廓都看不见（火花的存在感反而消失）。
> ⚠️ 日夜切换是**插值**的，`LightColor` 从 A 到 B 中间会经过两个色的混色，不会经过白色。

## 四 · C 区：M_CelLit_Default（全工程默认受光材质）

> 这个材质被 `Renderer2D.asset` 指定为 **Custom 默认材质**：任何没显式指定材质的 SpriteRenderer 都自动用它。
> 地面瓦片、玩家、敌人、掉落物、泉水/树/栅栏/箭头牌**共用同一个材质** —— 改这里 = 全场一起变。

| 属性名 | 现值 | 范围 | 含义 |
| :-- | :-- | :-- | :-- |
| `_AmbientFloor`（暗部保底） | **0.1** | 0 ~ 0.6 | 环境光的下限。**必须 ≤ 0.20**，否则 `max()` 会把整片夜色压平成中性灰 |
| `_TileLightBoost`（光场增强倍率） | **1.35** | 0.5 ~ 3.0 | 网格光场与随身光的**过曝余量**。调大=火光更"撕开"夜色，过大会削平渐变 |
| `_EmissiveBoost`（自发光增益） | **0.1** | 0 ~ 1.5 | 不看光照的自身提亮。**对全场所有精灵生效**，调高会整体发灰、夜色变脏 |
| `_Color`（整体染色） | 白 | — | 材质级乘色，一般不动（单体贴图色用 SpriteRenderer 的 Color） |
| `_EnableRim`（顶端高光开关） | **关** | — | 打开后才有下面三项效果 |
| `_RimThreshold`（高光起始高度） | 0.92 | 0.8 ~ 1.0 | UV.y 超过它才画高光。调低=高光带变宽 |
| `_RimColor`（高光颜色） | `#F9CE5A` | — | 明黄描边 |
| `_RimAlphaWeight`（高光按透明度加权） | 0.65 | 0 ~ 1 | `lerp` 权重上限。调低=高光更含蓄；调 0 = 高光消失 |
| `_MetalThreshold`（金属亮度阈值） | 0.85 | 0.7 ~ 0.95 | 像素亮度超过它的地方算金属高光 |
| `_MetalIntensity`（金属反光强度） | **0** | 0 ~ 1 | 0 = 金属反光整体关闭；调大才看得到 `_MetalThreshold` 的阶梯 |
| `_FlashAmount`（受击闪白强度） | 0 | 0 ~ 1 | **运行时由 `ActorTintDriver` 写入**，不要手改 |
| `_FlashColor`（受击闪白色） | 白 | — | 闪白颜色。改红=受伤更血腥，改白=干净 |

## 六 · 改了不生效清单（省你一次翻代码）

| 你以为能调 | 实际情况 |
| :-- | :-- |
| `TimeOfDaySetting.AmbientFloorColor` | **当前没有被任何代码消费**。真正生效的"暗部保底"是材质的 `_AmbientFloor`（§4/§5） |
| `_RimThreshold` / `_RimColor` / `_RimAlphaWeight` | `_EnableRim = 0` 时全部无效，先打开开关 |
| `_MetalThreshold` | `_MetalIntensity = 0` 时无效（默认就是 0） |
| Global Light 2D 的 `Color` / `Intensity` | 每帧被 B 覆写，手改会被冲掉。要改请用 §3.2 |
| 场景里挂 `TileLightDirector` | 该组件**已从场景移除**，只作光型表与回滚路径。加回来会让点光源与网格光场**叠加**，光斑重新变回正圆衰减 —— 那正是新范式要替换的东西 |
| `_TileLightmap` 当材质属性 | 它是**着色器全局量**，由 A 每帧注入。声明成材质属性会让材质值盖掉全局值 → 全场失光 |
| `M_TileFlow_Grass` 的 `_Flow*` | 无主键，见 §5.2 |

## 七 · 常用配方（照着抄）

| 诉求 | 操作 |
| :-- | :-- |
| 夜更黑、火更炸 | `Night.Intensity` → 0.15 ｜ `_TileLightBoost` → 1.6 |
| 火光只照亮身边（更有"火堆感"） | `airTransmission` → 0.75（半径 ≈ 8 格） |
| 大范围泛光（不那么压抑） | `airTransmission` → 0.85（半径 ≈ 14 格） |
| 火"呼吸"更慢更沉 | `fireBreathHertz` → 0.4，`fireBreathDepth` → 0.15 |
| 火**完全不动** | `fireBreathDepth` → 0 |
| 火光更黄（篝火而非岩浆） | `fireSourceColor` 绿通道拉高、蓝通道拉低 |
| 玩家脚下更亮 | `carryLightIntensity` → 0.8（注意会盖掉火光层次） |
| 夜里也能看清场地轮廓 | 别调 `_AmbientFloor`（会压平夜色）；改 `Night.Intensity` 到 0.25 或 `airTransmission` 到 0.85 |
| 水面/火场在夜里太暗 | 对应材质的 `_TileLightBoost` → 1.6 |
| 墙体阴影太软 | `obstacleTransmission` → 0.1 |
| 想要昼夜切换的演出感 | `transitionDuration` → 3 ~ 5 |

## 八 · 改完怎么验

1. 存盘后回 Unity，等重编译（只改材质属性时连重编译都不需要）。
2. **门禁**（改的是 C# 或 shader 时必须跑）：
   ```powershell
   pwsh Tools/compile-gate.ps1   # 必须 0 error / 0 warning
   pwsh Tools/comment-lint.ps1   # 必须 exit 0
   ```
3. **PlayMode 目视清单**：
   - 夜场景中央的火池：光斑是**圆润渐隐**，没有 45° 菱形、没有闪烁；
   - 玩家移动时脚下暖光**连续滑动**，不一格一跳；
   - 靠近火堆时**玩家/敌人/掉落物/泉水/树/栅栏**都会被暖光照亮，远端正常变暗；
   - 受击时角色闪白（走 `_FlashAmount` 通道）。
4. **零回归自检**：所有字段初值都等于上一版的硬编码常数，测试 `参数暴露_光照常数默认值必须与旧硬编码逐位对齐` 会替你守着；
   若它变红，说明有人改了"默认画面"，而不是在调参。

## 九 · 一张图看懂光是怎么算出颜色的

```
              ┌─ envLight = max(_ShapeLightTexture0, _AmbientFloor) ← 暗夜帷幕（保底只夹这一路）
最终光 = max ──┼─ _TileLightmap × _TileLightBoost                    ← 被撕开的那道火光
              └─ _CarryLightColor × exp2(-距离 × 每格衰减) × _TileLightBoost ← 玩家随身光
                     ↓
              贴图色 × 最终光 ＋ 自发光(_EmissiveBoost) ＋ 高光 / 闪白
```

三者**取大**而不是相加：这是"高反差夜色"的来源 —— 火光不会把夜色整体提亮，只在自己周围**顶掉**夜色。
`_AmbientFloor` 只夹环境光那一路：夹得太高（> 0.20）等于把夜色的黑抬成灰，火光就"爆"不出来了。
