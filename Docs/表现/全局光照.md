## 一、30 秒看懂

整套光照只干一件事：**让手绘色块在夜里被"抠"出亮区，而不是整体压暗**。因此光不靠 Light2D 的光圈堆叠，而靠一张**一格一纹素的网格光场**（泰拉瑞亚式）在格子上扩散，最后在片元里与 URP 的环境光**逐通道取大**。

```text
  EnvironmentDirector ──[Light2D Global: 颜色 × 强度]──► _ShapeLightTexture0 ─┐
  TileGridLightmap    ──[每帧两趟扩散 → RGBA32]──────► _TileLightmap        ├─► 逐通道 max ─► × 底色 ─► + 自发光 / Rim / Metal ─► lerp(闪白)
                      ──[随身光 exp2 衰减]──────────► _CarryLight*         ┘
```

| 光层 | 载体 | 谁写 | 受光对象 |
| :-- | :-- | :-- | :-- |
| 环境光（帷幕） | 场景唯一 `Global Light 2D`（`LightType=Global`） | `EnvironmentDirector`：进 Play、切时段、改字段即覆写 | `Ground` / `Actor` 两层 |
| 网格光场（主光） | `TileGridLightmap` 的 `Texture2D` + 4 个 shader 全局量 | `CombatRoot.RenderTick` → `Tick()` | 所有挂 `CelLit` 的件 |
| 自发光 / 伪高光 | 材质属性 | 美术调材质 | 同材质 |
| 点光源池（已停用） | `TileLightDirector`（历史件） | **无驱动者** | —— 见 §十 |

## 二、图层与受光隔离

**光照只按 Sorting Layer 过滤，无法按 Order 过滤** —— 所以"哪些层受光"是硬性拓扑，不是美术口味。

| 层 | `SortingLayer` uniqueID | Order 频带 | 受光 | 用途 / 材质 |
| :-- | :-- | :-- | :-- | :-- |
| `Default` | `0` | — | ❌ | 无（**ID=0 是坑**，见下） |
| `Ground` | `862251653` | 0 ~ 5 | ✅ | 地表瓦片：`M_CelLit_Default` / `M_TileFlow_*` / `M_TileFlow_Grass` |
| `Actor` | `223517723` | 310（贴地阴影）、400 ~ 1000（Y-Sort 频带） | ✅ | 角色、敌人、掉落物、立面覆件 |
| `Aim` | `1108840361` | 320 | ❌ | 瞄准/播种高亮（`HighlightDriver`） |
| `Effect` | `670872527` | 各特效自定 | ❌ | 粒子、电弧、飘字底、电格特效 |
| `UI` | `915327455` | 最上 | ❌ | 界面 |

### 2.1 掩码契约

- `Global Light 2D` 的 `m_ApplyToSortingLayers` **只能**是 `{Ground, Actor}` 两个 uniqueID（序列化里就是一串按 int 排的字节：`85ea64331b9c520d`）。
- **只能经序列化字段写**：`Light2D` 的照射层是私有字段且没有公共访问器；装配工具因此走 `SerializedProperty`。
- 🔴 **严禁运行期 `AddComponent<Light2D>()`**：`Awake` 会把照射层填成**全部层**，点光会漏照 `Effect` / `UI`。**点光只能从预制体实例化**（`Assets/Resources/lighting/TilePointLight.prefab`）。
- 机器判据：`CelLitMaterialTests.场景_Range的全局灯只照Ground与Actor`、`全局光照Tests.受光掩码_不包含UI特效与瞄准层`。

### 2.2 为什么 `Effect` / `UI` 必须断光

1. 夜里 Unlit 素材被压暗会**变成灰泥**：电弧、飘字、闪白全部失色。
2. 让光穿透到全屏层，混合代价从"几块瓦片"变成"整屏 DrawCall"。
3. 受击闪白是 0.12 s 的纯白剪影：在受光层被压暗，在 Unlit 层又会被 Bloom 放大成光斑 —— 两头都不对，见 §五 第 8 步。

### 2.3 两个已踩过的坑

- 🔴 **`Default` 层的 ID 是 0**：`RenderOrder.OverlayLayer = 0` 曾被当成"Default 层排序值"用，导致立面覆件被锁在**不受光**的 `Default` 层（白天正常、夜里整片发灰）。正确做法是显式 `sortingLayerName = Actor`，见 `TileOverlayDirector`。
- 🔴 **`M_SpriteFlash`（`SpriteFlash.shader`）不采样 `_TileLightmap`**：受击闪白的 Unlit 分支还在用，但**角色身体绝不能挂它**，否则"离火多远都一样亮"。

## 三、时段系统（`EnvironmentDirector`）

| 字段 | 脚本默认（`TimeOfDaySetting.GetDefault`，新场景初值） | 说明 |
| :-- | :-- | :-- |
| `initialTimeOfDay` | `Day` | 开局时段。**没有自动推进**：`TransitionTo` 目前无调用点 |
| `transitionDuration` | `1.5 s` | `SmoothStep` 插值时长；`0` 会瞬跳 |
| `daySetting` | `#FFFBF0` / `0.98` | 纯净暖白，保证手绘原画色相 1:1 |
| `duskSetting` | 线性 `(1, .4392, .2510)` / `0.75` | 暖橙黄昏：分量取自 Range 的拾色器结果 |
| `nightSetting` | 线性 `(0, 0, .6784)` / `0.25` | 纯蓝暗夜 |

- 颜色是**线性槽位**：只有白昼经 `ColorUtility` 从 `#FFFBF0` 线性化；黄昏/夜晚直接按 Range 现值写三分量（那就是拾色器给出的数，别再拿 hex 转一次，转了会压暗一档）。`Intensity` 带 `Range(0.15, 1.2)`，**低于 0.15 非受光区轮廓不可读**。
- **三段外观是场景字段**：Inspector 改完存场景就以场景为准；改 `GetDefault` 只影响新场景/重挂组件（这是"改了代码没效果"的头号原因）。
- 驱动：`Awake` 直接套用 `initialTimeOfDay` → `Update` 里按 `SmoothStep` 插值 → 到达后 `ApplySettingDirectly`；`SetTimeOfDayImmediate` 瞬切；`OnValidate` 让播放中改字段立刻见效（过渡中不抢写）。
- 主光的 `Color` / `Intensity` 是**调参手册 B 区的输出端**：手填 `Global Light 2D` 撑不到下一次切换。

> **2026-10 已把默认值对齐 `Range.unity` 现值**：三段外观、`initialTimeOfDay`（`Day`）、`transitionDuration` 与场景逐项相同，新场景/重挂组件拿到的就是 Range 手感。再手调场景后记得同步 `GetDefault`，否则两条路又会分叉 —— 机器判据只锁"强度下限 0.15 + 黄昏夜晚不撞色"，锁不住具体色值。

## 四、网格光场（`TileGridLightmap`，核心）

### 4.1 为什么不用 Light2D 点光

- URP 2D 一次混合的灯数有上限（历史任务书按 **16 盏**记），连片火海要 N 盏灯去覆盖 → 超限后失效/抽搐。
- Light2D 是**圆形衰减**，光斑永远是圆的；手绘要的是"贴着格子边缘撕裂"的形状。
- 网格场把开销从"灯数量"换成"格子数"：**连片火海天然融成一整块光区，灯具数量不再是开销项**。

### 4.2 数据与生命周期

| 成员 | 说明 |
| :-- | :-- |
| `_kindMap[]` | 每格光源类别：`0` 无 / `1` 火 / `2` 电。**唯一真源**，由格子事件写入 |
| `_blockedMap[]` | 每格是否光阻：`_grid.IsObstacle(cell)`（`is_obstacle` 列是唯一真源） |
| `_workR/G/B[]` | 扩散工作区，**必须 float**：`byte` 逐格截断会在十余格后突然断成 0，形成硬色阶 |
| `_pixels[]` / `_texture` | 一格一纹素，`RGBA32`，`Bilinear` + `Clamp`，**`linear: true`**（Linear 空间下标 sRGB 会二次解码、衰减全变形） |
| `_steadyEmitters` | 道具光（泉眼）列表，调用方**每帧重建** |
| `TexelWarnThreshold` | `96000` 纹素：超过就警告"逐帧两趟扫描会明显吃帧"（照建，不阻断） |

- `Attach(grid, geometry, cellBounds)`：建图 + 订阅 `EventBus<TileStateChanged>`；由 `CombatRoot` 在装配时调用，边界取自 `gridView` 的地板层。**缺 `grid` / 几何 / 地板层边界时只打一条 Warning 然后整场不发光**，排查"哪里都不亮"先看这条日志。
- `Detach()` / `ClearAll()`：退订 + 清空；`OnDestroy` 额外**复位 4 个全局量**（见 4.5）。
- `Tick(time, deltaTime)`：**唯一驱动入口**是 `CombatRoot.RenderTick`，顺序固定为「随身光位置 → 泉眼登记 → `Tick`」。

### 4.3 每帧管线（5 步，零 GC）

1. `PushCarryGlobals()`：随身光走着色器全局量，**不烘进纹理**，所以即使没有任何火/电格也要每帧推。
2. **空转判据**：`HasEmitters == false && !_wasLit` 直接返回（`HasEmitters` = 火/电格数 + 道具光数，**漏掉道具光会让"场上只有泉眼"时整条扩散停摆**）。
3. `FillSources`：火 = `fireSourceColor × 呼吸`；电 = `electricSourceColor × 阶跃`；道具光按格心 **逐通道 `max`** 写进同一张工作区。
4. `Propagate`：正/反两趟 8 邻域扫描，`Harvest(max(邻格) × 透过率)`。
5. `Upload`：量化到 `Color32` → `SetPixels32` + `Apply(false, false)` → 记录 `_wasLit`。

### 4.4 扩散数学

| 参数 | 脚本默认 | `Range.unity` 现值 | 含义 |
| :-- | :-- | :-- | :-- |
| `airTransmission` | `0.72` | `0.75` | 每跨一格的保留率（衰减半径 ≈ `-log₂(a)` 格） |
| `obstacleTransmission` | `0.20` | `0.20` | 光穿过光阻格的剩余比例（越低阴影越硬） |
| `diagonalTransmissionExponent` | `1.4142` (√2) | `1.4142` | 对角一步按 `a^√2` 衰减 |

- 对角必须按 `a^√2`（≈走 √2 格）：取 `a × 0.707` 会小于 `a²`，对角项永远输给两步正交，**菱形走样一点都消不掉**。
- 墙体衰减**按目的格判定**：光穿墙后再跨一格还要再乘一次空气透过率 → 墙背后才形成硬边阴影。
- 工作区是逐通道 `max`，不是加法：三口泉并排、或泉压在火格上，都**不会叠加过曝**，也不会互相抹掉。

### 4.5 注入给着色器的 4 个全局量

| 全局量 | 内容 | 未装配/关闭时 |
| :-- | :-- | :-- |
| `_TileLightmap` | 光照图纹理 | `Texture2D.blackTexture` |
| `_TileLightmapParams` | `xy` = 左下角世界坐标，`zw` = 宽高（世界单位） | `Vector4.zero`（着色器 `onFlag = 0`，退回纯环境光） |
| `_CarryLightPos` | `xy` = 世界坐标，`z` = 每格 `-log₂(airTransmission)`，`w` = 强度 | 零 |
| `_CarryLightColor` | 随身光颜色 | 零 |

- `_TileLightmapParams` 的角点是**格心减半格**：纹素中心必须落在格心上，否则整张光场偏移半格。
- 随身光的 `z` 与网格共用同一条衰减率 → 改 `airTransmission`，随身照亮的范围会一起跟着变。
- 🔴 `OnDestroy` 必须把 4 个全局量复位：纹理销毁后仍被材质引用会**画成整片洋红**。

### 4.6 光源参数与节奏

| 光种 | 参数（默认 = 场景现值，2026-10 对齐） | 节奏 |
| :-- | :-- | :-- |
| 火格 | `fireBreathHertz 0.7`、`Depth 0.10`、`Base 1.0`；`fireSourceColor (1, .549, .259)` | 正弦呼吸，>1.5 Hz 就从"呼吸"变"闪烁" |
| 电格 | `electricJitterHertz 18`、`Floor 0.85`、`Depth 0.15`；`electricSourceColor (.147, .157, .25)` | **硬阶跃**，档位用黄金分割低差异步进（换伪随机会连着重播同档） |
| 随身光 | `carryLightColor (.496, .496, .465)`；`carryLightIntensity 0.10` | `exp2(-距离 × 衰减率)`，世界坐标连续推进，不参与遮挡 |
| 道具泉眼 | `steadyPulseHertz 0.35`（全局节拍）+ 泉眼组件四项（`selfLightIntensity` / `PulseDepth` / `overrideSelfLightColor` / 光色） | 同一张网格逐通道取大；泉眼参数**每帧重读**，播放中拖动即时生效 |

> **场上现值提示**：电色被压到近黑蓝 `(.147, .157, .25)`（电格几乎不照亮地面，视觉由电格粒子承担）；随身光只剩 `0.10` 的中性灰，夜里脚下是一圈很淡的轮廓。这两项离"设计初值"最远，排查"电格不发光 / 夜里看不见脚"先看这里。

## 五、受光着色器契约（`CelLit`）

资产：`Assets/Resources/materials/M_CelLit_Default.mat`（地表、角色、敌人、掉落物、立面覆件共用）；属性逐项说明见调参手册 C 区。

**片元固定 8 步序**（`Assets/Resources/materials/Shaders/CelLit.shader`）：

1. `envLight = max(_ShapeLightTexture0, _AmbientFloor)` —— 环境光即夜色本体；`_AmbientFloor` 是**保险丝不是调色旋钮**（逐通道取大，抬高就把三通道一起抹平）。
2. `gridUV = (worldPos - _TileLightmapParams.xy) / zw` → 采 `_TileLightmap`，乘 `onFlag`（`zw == 0` 时整段乘没）。
3. `carryLight = _CarryLightColor × _CarryLightPos.w × exp2(-距离 × .z)`。
4. `finalLight = max(env, tile × _TileLightBoost, carry × _TileLightBoost)` —— **取大不叠加**。
5. `finalRgb = base × finalLight`。
6. `+= base × _EmissiveBoost`（瓦片自发光，火海自己亮）。
7. Rim（`uv.y > _RimThreshold` 时 lerp）/ Metal（亮度阈值阶梯）—— 各有总开关。
8. `lerp(finalRgb, _FlashColor, _FlashAmount)` —— **闪白必须最后一步**，这样它不会被夜色与 `_AmbientFloor` 压暗，也不会把 Unlit/受光拆成两套材质。

**两条布局铁律**：

- 🔴 `_TileLightmap` / `_TileLightmapParams` / `_CarryLight*` **严禁声明成材质属性**：材质里的默认值会盖掉 C# 写的全局值，表现为**全屏黑斑或整片不亮**。
- 🔴 全局量必须写在 `CBUFFER(UnityPerMaterial)` **之外**：塞进去会破坏 SRP Batcher 的常量布局。
- 机器判据：`TileGridLightmapTests.参数暴露_着色器新增系数必须同时写进属性与常量缓冲`、`着色器_CelLit已接入网格光照图且已剔除硬阶与时间抖动`、`CelLitMaterialTests.材质_受光材质的暗部保底不得高于0点20`。

**其它受光件**：`TileFlow`（水面/火海流体，逐格相位噪声，**不做 Cel 量化**）、`TilePlantFlow`（草丛摇曳，`_HeightCutoff` 以下冻结）。两者共用同一套光照量，改动时别把 `_TileLightBoost` 漏掉。

> `_ShapeLightTexture0` 由 `USE_SHAPE_LIGHT_TYPE_0` 宏门控：**宏没启用时 `envLight` 退化为纯白**，画面看起来"永远白天"。换渲染管线资产 / Blend Style 后出现这个症状先查宏。

## 六、后处理封印（`Global Volume`）

- 载体：`Range.unity ▸ [Environment] ▸ Global Volume`（`isGlobal = true`，`priority 0`）→ `Assets/Settings/DefaultGlobalVolumeProfile.asset`。
- 装配入口：`DeepseaOil ▸ 光照 ▸ 装配当前场景`。

| 组件 | 工具写入 = 资产现值（2026-10 对齐） | 为什么 |
| :-- | :-- | :-- |
| `Tonemapping` | **移除**（资产里不存在） | 任何 tone curve 都会把 2D 纯色块压出灰雾；ACES 尤其拉脏暗部 |
| `ColorAdjustments` | `postExposure 0.2` / `contrast 0` / `saturation -10` | 手调过一轮：轻微提亮 + 抽掉一点饱和，让手绘色不"发柴"；对比交给 Bloom 与夜色分离 |
| `Bloom` | `threshold 1.15` / `intensity 5` / `scatter 0.60` | 阈值 >1 是"受击纯白剪影不糊成大白斑"的核心保险；intensity 5 是美术要的明显泛光 |
| `Vignette` | `#1E1E1D` / `0.10` / `0.40` | 深灰不压纯黑，对齐 UI 底色 |

> ✅ **2026-10 已收口**：工具封印值就是资产现值，`LightingVisualCorrectionTests.后处理_Tonemapping已剔除且封印值已注入` 现在应当是绿的（`contrast 0` / `saturation -10` / `Bloom 5` / `Vignette 0.10`）。改任一侧都要同步另一侧，否则该用例当场变红。

## 七、硬约束速查（改光照前过一遍）

1. 改环境色改 **B 区三段外观**，别手填 `Global Light 2D`。
2. `Global Light 2D` 的 `m_ApplyToSortingLayers` 只允许 `Ground` + `Actor`；`Effect` / `Aim` / `UI` 受光 = 夜色发灰 + 特效失色。
3. 点光**只能**从 `TilePointLight.prefab` 实例化，**严禁运行期 `AddComponent<Light2D>`**（照射层会被填成全部层）。
4. `_TileLightmap*` / `_CarryLight*` 是**全局量**：不做材质属性、不进 `UnityPerMaterial`、`OnDestroy` 里必须复位。
5. 光照图纹理必须 `linear: true`；一格一纹素；`_TileLightmapParams` 的角点 = 格心减半格。
6. 扩散工作区必须 `float`（`byte` 会在十余格后断成 0）。
7. 对角衰减指数固定 √2，**不许** ≤1（退化成十字）或 ≈0.707（退回菱形走样）。
8. `_AmbientFloor ≤ 0.05`（材质基准 0.02）：它是保险丝，抬一点就把夜色抹成中性灰。
9. 角色身体必须挂受光材质（`M_CelLit_Default`），**不能**挂 `SpriteFlashUnlit`。
10. 闪白永远在 `CelLit` 末端（最后一 lerp），不许为闪白另开 Unlit 材质。
11. 驱动入口只有 `CombatRoot.RenderTick`（网格场）与 `EnvironmentDirector.Update`（时段过渡插值；这是唯一没收敛进 `GameRoot` 的 Update，属已知偏离）；**别在业务组件里加 `Update` 刷光**。
12. 暂停时 `Time.time` 不推进 → 呼吸/阶跃冻结在那一档，是预期行为，不是丢帧。
13. 时段**没有自动推进**：想看黄昏/夜晚就把 `Initial Time Of Day` 改掉再进 Play，或自己接波次时序。
14. 泉眼落在光照图边界外只会打**一条**警告然后完全不亮（边界取自地板层）。
15. 改动后必须过两道门：`pwsh Tools/compile-gate.ps1`（0 error / 0 warning）与 `pwsh Tools/comment-lint.ps1`（退出码 0）。
