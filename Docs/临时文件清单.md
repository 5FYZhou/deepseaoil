## 7. 自检入口

```powershell
pwsh Tools/audit.ps1 -Full
```

一条命令四段：静态检查 → 全量语义编译（编译 Unity 自己生成的 `.csproj`，与 Console 一致）→ 目录树同源 / 断链 / mermaid 校验。**顺序不可换**：编译不过时后面全是空跑。

Unity 侧三个菜单（都在 `Tools ▸ 深海石油 ▸` 下）：搭建移动测试场景 / 校验移动与相机接线 / 相机跟随诊断。它们是**本次的脚手架**，随代码推翻可一并推翻。
