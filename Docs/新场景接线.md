# 新场景接线操作清单

一个可玩场景需要：`GameRoot` / `InputProvider` / `PlayerController` / `CombatRoot` / `TilemapAdapter` / 有地板的 Tilemap / 主相机 / Global Light 2D。
**禁止**：场景里放 `Canvas` / `EventSystem` / 第二个 `AudioListener`（UI 三件套由 `UIMgr` 从 `Assets/Resources/ui/` 自动创建）。

## 步骤 1：建场景

打开 `Assets/Settings/Scenes/URP2DSceneTemplate.unity` → `File ▸ Save As` 存成你的场景。它自带主相机（正交 Size 5、tag `MainCamera`）和 Global Light 2D。
自己建空场景则**必须手动加 Global Light 2D**，否则受光精灵全黑。

## 步骤 2：Tilemap

1. `GameObject ▸ 2D Object ▸ Tilemap ▸ Rectangular` → 得到 `Grid` 及其子物体 `Tilemap`
2. 子物体改名 `Ground`；复制一份改名 `TileEffect`（初始留空）
3. `Window ▸ 2D ▸ Tile Palette` 打开 `Assets/Art/TileMap/demoTile/Demo_Palette.prefab`，在 **Ground** 层刷出地板（`Tile_Floor`），至少一格
4. 两层 `TilemapRenderer ▸ Sorting Order`：Ground = 0，TileEffect = 1

## 步骤 3：GridView

新建根物体 `GridView`，挂 `TilemapAdapter`：

| 字段 | 值 |
| :-- | :-- |
| `groundTilemap` | 拖 Ground 的 Tilemap |
| `effectTilemap` | 拖 TileEffect 的 Tilemap |
| `stateTiles` | Size 1；Element 0：`State = Mud`，`Tile = Tile_Mud.asset` |

## 步骤 4：BoundsArea（可选）

新建 `BoundsArea`：加 `BoxCollider2D` → **`Is Trigger` ✓** → `Size` = 可走区域（如 40×20）→ 位置放在区域中心。

## 步骤 5：玩家

新建 `Player`：

| 组件 | 字段 | 值 |
| :-- | :-- | :-- |
| Transform | Position | 出生点 |
| Rigidbody2D | Gravity Scale | 0 |
| | Constraints | Freeze Rotation Z ✓ |
| | Collision Detection | Continuous |
| | **Interpolate** | **Interpolate** |
| BoxCollider2D | Size | (0.7, 0.5)，非 Trigger |
| SpriteRenderer | Sprite | 任意色块（如 `Assets/Resources/demo/Square.png`） |
| PlayerMotor | `body` | 留空（自取） |
| PlayerController | `motor` | 拖自己身上的 PlayerMotor |
| | `inputProvider` | 拖步骤 6 的 InputProvider |
| | `aimCamera` | 留空（默认取 `Camera.main`） |
| | `boundsArea` | 拖 BoundsArea 的 BoxCollider2D |

> `SpriteRenderer` 必须和 `PlayerController` 同一个 GameObject（Y 排序每帧从它取本体）。
> 玩家数值不在这里拖：`ConfigModule.BindAssets` 读 `Assets/Resources/config/PlayerConfig.asset`。

## 步骤 6：InputProvider 与 GameRoot

各建一个空物体，分别挂 `InputProvider` 与 `GameRoot`，**没有需要拖的字段**。

## 步骤 7：CombatRoot 与 Fountain

| 对象 | 字段 | 值 |
| :-- | :-- | :-- |
| `CombatRoot` | `player` | 拖 PlayerController（必需） |
| | `gridView` | 拖 TilemapAdapter（必需） |
| | `ballRoot` / `actorRoot` | 可空 |
| | `fountains` | 拖喷泉（可空） |
| | `enableWaves` | ✓ |
| `Fountain` | CircleCollider2D | **Is Trigger ✓**，Radius 3 |
| | `spawnInterval` | 1 |
| | `landingRadius` / `minLandingDistance` | 3 / 0.8 |

## 步骤 8：Cinemachine（可选）

1. 主相机加 `Cinemachine Brain`（用 CM 菜单建 vcam 会自动加）
2. `GameObject ▸ Cinemachine ▸ 2D Camera`
3. vcam 设置：

| 字段 | 值 |
| :-- | :-- |
| `Follow` | 拖 Player |
| `Look At` | 留空 |
| `Lens ▸ Orthographic Size` | 5 |
| `Body ▸ Framing Transposer ▸ Camera Distance` | 10 |
| `Body ▸ Framing Transposer ▸ Damping` | 0.15~0.3 |
| `Aim` | Do nothing |
| Brain ▸ Update Method | SmartUpdate |

4. （可选）限制相机不出图：vcam 加 `CinemachineConfiner` 扩展 → `Confine Mode = Confine2D`，`Bounding Shape 2D` 拖 `BoundsArea` 的 BoxCollider2D，`Confine Screen Edges ✓`

## 启动验收

进 Play，Console 应出现：

```
[Combat] 装配完成：格子 N 个（初始状态 0 个），球种 2 个，喷泉 M 个，敌人 启用
```

- 此时是菜单态（暂停），点 `BeginPanel` 的 `StartBtn` 开始
- WASD 移动、Shift 冲刺、左键水球、右键土球
- 走进喷泉圈等 1 秒拿水球；踩泥浆变慢；敌人追来接触掉血

## 最小排错表

| Console 文案 | 修法 |
| :-- | :-- |
| `PlayerController 引用未接线` | 检查步骤 5 的 motor / inputProvider |
| `CombatRoot 引用未接线` | 检查步骤 7 的 player / gridView |
| `[Grid] 地板 Tilemap 上一个 tile 都没有` | 在 Ground 层刷地板 |
| `[Grid] TilemapAdapter 的 groundTilemap 与 effectTilemap 指向了同一层` | 分两层 |
| `[UI] 场景里已经有一份 EventSystem` | 删掉场景里的 Canvas / EventSystem |
| `[Ball] projectile 表里没有球种 X` | 跑 `Luban ▸ 表格数据导入` |
| 点鼠标没反应 | 主相机 tag 是否是 `MainCamera` |
| 玩家 / 地板发黑 | 加 Global Light 2D |
| 相机不动 | vcam 的 `Follow` 是否接上 |
| 相机抖 | Player 的 `Rigidbody2D.Interpolate` 是否是 Interpolate |
| 玩家被看不见的墙挡住 | `BoundsArea` 的 `Is Trigger` 是否勾上 |
