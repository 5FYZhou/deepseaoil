# 目录说明

每个文件夹装什么。目录树由 `仓库一致性Tests.目录说明与磁盘同源` 守着：树里每个路径都会被断言真实存在于磁盘上（一目录/一文件占一行，缩进单位 4 字符，名字与注解之间 ≥2 空格）。

## 仓库目录

## 根目录文件

| 文件 | 作用 |
| :-- | :-- |
| `README.md` | 落地页，指向 `Docs/目录说明.md` |
| `.gitignore` / `.gitattributes` | 忽略规则（`Library/`、`Temp/`、`Logs/`、`ConfigWorkspace/output\|logs/`、`node_modules/`）；LFS 与换行符规则 |
| `deepseaoil.sln` / `*.csproj` / `.vsconfig` | Unity 自动生成、已在 `.gitignore` 里；`.vsconfig` 与配表无关 |

## 三处生成物禁区

放在这些位置的手写文件会被**静默删除** —— 不报错，只是下次生成后不见了。生成类都是 `partial`，要扩展就另建文件。

| 目录 | 谁生成 | 何时覆盖 |
| :-- | :-- | :-- |
| `Assets/Scripts/Generated/Config/` | Luban 导表（`-c cs-simple-json`） | 每次导表整目录镜像覆盖，暂存区没有的文件被删除（`.meta` 例外保留） |
| `Assets/StreamingAssets/Luban/` | Luban 导表（`-d json`） | 同上 |
| `Assets/Scripts/Generated/Input/InputSys.cs` | Input System 从 `Presentation/Input/InputSys.inputactions` 生成 | `.inputactions` 被重新导入/修改时整体重写（文件头写着 manual edits will be discarded） |

## `Assets/Resources/` 的字符串 Key

这些 Key **由路径派生**，动 `Assets/Resources/` 下任何文件都当场断链——**不报编译错，只有运行期加载失败**。
转换点唯一：`Data/Asset/AssetRegistry.cs`。

| Key | 解析到 | 出现位置 |
| :-- | :-- | :-- |
| `ui/UICamera` / `ui/Canvas` / `ui/EventSystem` | `Assets/Resources/ui/<名字>.prefab` | `Presentation/UI/UIMgr.cs` |
| `ui/Panel/<面板类名>` | `Assets/Resources/ui/Panel/<面板类名>.prefab` | 同上（**预制体名必须等于面板类名**） |
| 表里 `icon` 字段 | 形如 `Resources\Icons\xxx.png`：相对 `Assets/` 带扩展名 | Excel → `StreamingAssets/Luban/*.json` |

表里存「相对 `Assets/` 带扩展名」，`Resources.LoadAsync` 要「相对 `Assets/Resources/` 不带扩展名」。
⚠️ 表值还**必须落在 `Assets/Resources/` 下**——导表期只校验「在 `Assets/` 下存在」，填错地方导表不报错、运行期黑屏。

## 三层 ↔ 目录 ↔ 命名空间

层由**命名空间**判定，不是目录（两者现在一致）。

| 目录 | 命名空间 | 层 |
| :-- | :-- | :-- |
| `Scripts/Data/` | `DeepseaOil.Data` | 数据层 |
| `Scripts/Logic/` | `DeepseaOil.Logic` ＋ `.Movement[.States]` / `.Player` / `.Input` / `.Events` / `.Service` | 逻辑层 |
| `Scripts/Presentation/` | `DeepseaOil.Presentation` ＋ `.UI` | 表现层 |
| `Scripts/Foundation/` | `DeepseaOil.Foundation` | 不属层：与游戏无关的地基 |
| `Scripts/Generated/` | `cfg` / `cfg.demo` / `DeepseaOil.Generated` | 不属层：机器生成 |
| `Editor/` | `DeepseaOil.EditorTools` | 独立程序集 |
| `Tests/Tools/` · `Tests/Runtime/Editor/` | `DeepseaOil.EditorTools.Tests` · `DeepseaOil.Tests` | 测试 |

🔴 `Tests/Runtime/Editor/` 的**末级目录名 `Editor` 不可改、也不能加 asmdef**：靠这个名字落 `Assembly-CSharp-Editor`，
才能引用 `Assembly-CSharp` 里的运行时代码。加了 asmdef 的 `Tests/Tools/` 反而够不到 `Assembly-CSharp`。
