## 生成物禁区

放这些位置的手写文件会被**静默删除**——不报错，下次生成后就不见了。

| 目录 | 谁生成 |
| :-- | :-- |
| `Assets/Scripts/Generated/Config/` | Luban 导表 |
| `Assets/StreamingAssets/Luban/` | Luban 导表 |
| `Assets/Scripts/Generated/Input/InputSys.cs` | Input System 生成 |

不可动：`Assets/Resources/**`、`Assets/Editor/**`、`Tests/Runtime/Editor/` 的末级 `Editor`。

## 白模

白模（`Assets/Scripts/Prototype/`、`Assets/Scripts/Prototype2/`）是隔离环境里的临时代码与硬编码数值，
玩法已迁进三层框架并验收通过，按迁移决策 **D5** 整体删除 —— **本仓库当前已不含 `Assets/Scripts/Prototype*/`**，
两份白模 EditMode 测试（`白模抛球Tests` / `白模敌人Tests`）与 `Docs/toAgent/白模接入.md` 已同批删除
（`git log` 里仍可取回）。当年那份《迁移完成报告》随 `Docs/temp/` 一起清空，不再指向已删文件。

白模时代留下的**仍然在用的两样**：`Assets/Scripts/Presentation/Primitive/`（`PrimitiveSprites`：
运行期造图元，正式美术件不依赖它）与 `Assets/Scenes/TextTile.unity`（**已废弃**，见《框架设计/框架蓝图.md》缺陷登记 N6，建议删除）。
