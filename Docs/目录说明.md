## 命名约定

- **层与层之间没有 asmdef 边界**，命名空间是唯一的边界表达。`Assets/Scripts/**` 全部落 `Assembly-CSharp`（`Assets/Editor/` 落 `DeepseaOil.EditorTools`，`Assets/Tests/Tools/` 落 `DeepseaOil.EditorTools.Tests`）。
- 命名空间 = 目录名，四个例外（这些目录落**上级**命名空间）：`Logic/Actor[.States|.Status]`、`Logic/Bounds/`、`Logic/Input/GameState.cs`、`Presentation/Root|Audio/`、`Presentation/UI/MonoMgr.cs`、`Presentation/IDrivenEntity.cs|ISceneRoot.cs`。
- 另有四处**名字不同**：`Logic/Event/` → `.Events`（复数）、`Logic/Services/` → `.Service`（单数）、`Presentation/Diagnostics/`（**不能**叫 `Debug`：`DeepseaOil.Presentation.Debug` 会让本层所有 `Debug.LogError` 变成 CS0234）。
- 只有 `GameRoot` 是真单例；`MonoMgr` 是"临时例外、保持现状"。进程级件（UI / 音频 / 游戏状态 / Data 层）一律由 `GameRoot` 装配并持有。

## 生成物禁区

放这些位置的手写文件会被**静默删除**——不报错，下次生成后就不见了。

| 目录 | 谁生成 |
| :-- | :-- |
| `Assets/Scripts/Generated/Config/` | Luban 导表 |
| `Assets/StreamingAssets/Luban/` | Luban 导表 |
| `Assets/Scripts/Generated/Input/InputSys.cs` | Input System 生成 |

不可动：`Assets/Resources/**`、`Assets/Editor/**`、`Tests/Runtime/Editor/` 的末级 `Editor`。
`ConfigWorkspace/Tools/Luban/` 是 Git LFS 内容（`*.dll` / `*.exe`），**不要装 Luban 的 UPM 包**：与本地拷贝撞名，整个工程都编译不出来。
