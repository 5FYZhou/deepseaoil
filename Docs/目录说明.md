## 生成物禁区

放这些位置的手写文件会被**静默删除**——不报错，下次生成后就不见了。

| 目录 | 谁生成 |
| :-- | :-- |
| `Assets/Scripts/Generated/Config/` | Luban 导表 |
| `Assets/StreamingAssets/Luban/` | Luban 导表 |
| `Assets/Scripts/Generated/Input/InputSys.cs` | Input System 生成 |

不可动：`Assets/Resources/**`、`Assets/Editor/**`、`Tests/Runtime/Editor/` 的末级 `Editor`。
