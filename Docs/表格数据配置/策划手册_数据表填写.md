# 策划手册：数据表填写

## 1. 导一次表

| 步 | 动作 |
| :-- | :-- |
| 1 | `Git` 拉取最新改动 |
| 2 | 改 `ConfigWorkspace/Data/` 下的表格（表头 4 行见 §2） |
| 3 | **保存** |
| 4 | **关闭 Excel**（否则锁住文件，导表读不到） |
| 5 | 切回 Unity，按 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd>（菜单 `Luban ▸ 表格数据导入`；<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> 是仅校验，只报错不写盘） |
| 6 | `Git` 提交：表格与 `Assets/Scripts/Generated/Config/`、`Assets/StreamingAssets/Luban/` 下的生成物一起提交 |

**导入失败不改动工程里任何文件，反复重试是安全的。** 报错照 §3 改。

## 2. 怎么调表

工作路径：

![p3](image\p3.png)

### 表头四行

| 行 | A1 列 | 非 A1 列填什么 | 例 |
| :-- | :-- | :-- | :-- |
| 1 | `##var` | 程序字段名，**只允许小写英文和下划线** | `atk_speed` |
| 2 | `##type` | 数据类型，见下表 | `float` |
| 3 | `##group` | 分组，目前一律填 `c`（client 客户端） | `c` |
| 4 | `##comment` | 中文注释，会写成程序里的注释 | `攻速` |
| 5 起 | 空 | **数据从这里开始，第 1 列不填** | `1.2` |

![p4](image\p4.png)

### 数据类型（第 2 行）

| 我要什么 | 写什么 | 留空会怎样 |
| :-- | :-- | :-- |
| 整数 / 小数 / 文字 / 是否 | `int` / `float` / `string` / `bool` | 0 / 0 / 空 / 否 |
| 必须填 | `int!` `float!`（加叹号） | 报错 |
| 限范围 | `int#range=[1,100]`；`[1,]` 表示 1 到无穷 | 报错 |
| 引用他表（外键） | `int#ref=demo.TbItem` | 报错 |
| 引用可空 | `int#ref=demo.TbItem?` | 不报 |
| 限定取值 | `int#set=5` / `int#(set=1,2,3)` | 报错 |
| 资源路径 | `string#path=unity`，填**相对 `Assets`** 的路径 | 不报 |

- 限制符写在**类型行**，不写数据格。
- 多值必须**括号 + 逗号**；用 `;` 直接报错。
- 🔴 程序**只能加载 `Assets/Resources/` 下**的资源。导表期只校验"文件在 `Assets/` 下存在"，不校验它在 `Resources/` 下——填了别处的路径**导表不报错，运行期黑屏**。资源一律放 `Assets/Resources/` 下再填。

### 加表

表格文件自己建，但**必须登记**：在 `ConfigWorkspace/Data/__tables__.xlsx` 加一行。

| 列 | 填什么 | 例 |
| :-- | :-- | :-- |
| `full_name` | 模块名 + `Tb` + 记录名 | `demo.TbFish` |
| `value_type` | 记录类名 | `Fish` |
| `input` | 表格文件名 | `fish.xlsx` |
| `index` | 主键字段 | `id` |
| `output` | 生成的数据文件名 | `demo_tbfish` |

![p5](image\p5.png)

### 加列

**可以插在任意位置**，包括两个已有字段之间。插入一列 → 填齐 4 行表头 → 逐行补数据格（留空可以，但**数字格留空会变成 `0`**）→ 保存 → 关 Excel → 导表。

![p6](image\p6.png)

### 登记枚举

在 `ConfigWorkspace/Data/__enums__.xlsx`：`full_name` 写完整枚举名（如 `demo.Quality`），**每个枚举项占一行**。

## 3. 报错对照

| 报错片段 | 我该改哪一格 |
| :-- | :-- |
| `位置:[D5] abc` / `abc 不是 int 类型值` | `weapon.xlsx` D5。这列只能放数字 |
| `'普通剑' 不是 enum:'demo.Quality' 的有效枚举值` | 品质列。改成 `普通`/`精良`/`史诗` |
| `durability:999 … 不在范围:[1,100] 内` | 编号 1 那行的耐久度 |
| `durability:0 … 是一个默认值` | 那格没填。数字格空着变 0，补一个值 |
| `best_weapon = 9 … 在引用表…中不存在` | 编号 1001 那行的推荐武器。改成武器表有的编号 |
| `icon:… 找不到对应文件` | 编号 3 那行的图标格。改成存在的路径 |
| `有表格正被 Excel 占用` | 不用改格子。保存并**关闭**名单里的表 |

改完重新导表。Console 里 `[Luban] 完整日志：` 指向的文件有全部输出。
