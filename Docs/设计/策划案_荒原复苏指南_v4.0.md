## 一、核心玩法哲学与定位

**类型**：俯视角 2D 策略生存追逐战 · 像素复古朋克
**玩家定位**：携带聚合水罐与土箱的**荒原环境改造工**

你不是法师，不呼风唤雨。你手里只有两样东西：**水**和**土**。
战场上真正致命的是那些**原本就在那里**的东西——地热喷孔、漏电桩、干冰裂缝、枯萎荆棘。
你的全部本事，是用水和土去**借它们的力**。

### 三条设计铁律

| 铁律 | 含义 | 反面教材（已被物理删除，别复活） |
| --- | --- | --- |
| **所见即所得** | 画面上是水就是水。不允许存在"这格水湿度是 3 还是 4"这种美术画不出、玩家算不清的隐藏维度 | 温度 `-6~6` / 湿度 `0~6` / 导电 `0~2` 三轴连续值 |
| **离散查表** | 一切反应是「原格地貌 + 投入球种 → 结果地貌」，O(1) 查表，一次命中 | 标签位 + 三区间 + 导电下限的四条件合取匹配，18 行规则靠表序决定谁赢 |
| **首跳当帧** | 产生伤害的地貌，落地瞬间立刻结算第 1 下 | 生成蒸汽后敌人站在上面跳 0 点伤害（等第一次 Tick 才掉血） |

## 二、三泉鼎立：资源与生命的空间解耦

地图上有三个固定设施，职能**彻底分开**——这是全部战术张力的来源。

```
                 【北侧 · 高压水井】(Water Well)
                 汲取水弹药（上限 5）· 冲刺路过即补满
                            ▲
                           ╱ ╲
                          ╱   ╲
                         ╱     ╲

   【西南 · 裂解土丘】(Earth Mound) ────── 【东南 · 生命神泉】(Life Totem)
   汲取土弹药（上限 5）                      全图唯一的回血站
   冲刺路过即补满                            九宫格内完全静止 3 秒 → 恢复 1 颗心
```

### 为什么必须分开？

| 泉眼 | 玩法角色 | 玩家的心理 |
| --- | --- | --- |
| 高压水井 | **机动补给线** | "顺路补满，不心疼" |
| 裂解土丘 | **机动补给线** | 同上 |
| 生命神泉 | **高危 ICU** | "想回血？先想清楚这 3 秒谁替我挡" |

### 核心博弈闭环（本作的命门）

> 玩家**固定 5 颗心**（`player.max_hp = 5`），被碰到就按 §7 敌人表的贴身伤害扣血（普通怪 1 / 精英怪 2），没有任何数值成长。
> 想回血，必须在神泉九宫格内**完全静止 3 秒**。

静止 = 站着不动挨打。所以真正的解法不是"跑过去站着"，而是：

1. 提前在追兵路线上铺 **普通泥浆**（移速 ×0.5，存活 10 秒）——把敌人拖成一条线；
2. 或者用 **陶砖**（实体阻挡，存活 15 秒）把路堵成漏斗，逼大部队绕远路；
3. 或者触发 **燎原火海**（2 点/秒）把追兵烧穿在到达之前；
4. 然后才敢走进神泉，站满 3 秒。

**"完全静止"的三重判据**（代码里 `LifeFountainState` 实现，可在 EditMode 直测）：
- 无移动输入
- 引擎回读速度 < 0.05 世界单位/秒（`SpeedEpsilon`）
- 单帧位移 < 0.002 世界单位（`MoveEpsilon`）

三条任一不满足即**清零累计**（不是暂停——离开要重新站满）。神泉**满血时不回血**，累计同样清零。

## 三、交互拓扑：双键即时 + E 键波前基建

零心智负担：不谈背包、不谈滚轮、不谈选种子弹窗。

| 输入 | 动作 | 消耗 |
| --- | --- | --- |
| **鼠标左键 (LMB)** | 喷射纯水 | 1 水弹药 |
| **鼠标右键 (RMB)** | 投掷纯土 | 1 土弹药 |
| **E 键** | 播种当前战备种子 | 1 颗种子 |
| **左 Shift** | 战术冲刺（带 CD 与输入缓冲） | — |
| **WASD** | 走位 | — |
| 走进泉眼九宫格 | 自动汲取弹药（无需按键） | — |

播种的合法性是**唯一判据**（`SeedPlanter.CanPlant`）：**只能播在空地上**（`grid.StateOf(cell) == Normal`）。
已有地貌 → 拒绝（`PlantRejection.NotEmpty`）。光标预览：可播 **白**（`VisualPalette.highlightAvailable` = 白、alpha 0.32），不可播 **红**（`highlightBlocked` = 红、alpha 0.42）。

> **输入接线现状**：`Attack / AltAttack / Plant / Aim` 四个动作登记在
> `Assets/Scripts/Presentation/Input/InputSys.inputactions` 的 `Player` 地图里，
> 由 `InputProvider` 用 `FindAction` 取用。改动动作表**不需要**重新生成 `InputSys.cs`；
> 代价是这四个键暂时不进"键位重绑"（当前也没有重绑 UI）。
> **键位与实现的对应**：冲刺 = `Player/Dash` = `leftShift`；`Player/Jump` 绑的是 `space`，
> 玩家没有跳跃能力，`Assets/Scripts` 下**零消费者**；播种 = `Player/Plant` = `e`
> （`Player/Grab` 同键，同样零消费者）；`Attack` / `AltAttack` = 鼠标左 / 右键，`Aim` = 鼠标位置。

## 四、资源界线：主动 vs 环境

| 类别 | 实体形态 | 获取 / 存在方式 | 生命周期 | 视觉特征 |
| --- | --- | --- | --- | --- |
| **主动·水** | 玩家水球 | 水井汲取（补满 5）/ 水滴掉落 | 弹药池，每次投掷 −1 | 蔚蓝抛物线，落地水花 |
| **主动·土** | 玩家土块 | 土丘汲取（补满 5）/ 土块掉落 | 弹药池，每次投掷 −1 | 棕黄抛物线，落地碎石 |
| **战略·种子** | 战备种子 | **波前按 `wave.grant_seed` 配给**（W1~W3 无 / W4~W6 火种子）/ 精英怪掉落 1 颗（4 种等权、必掉） | 单槽持有，播种即消耗 | 插桩动作 + 落点高亮 |
| **环境·火** | 地热喷孔 / 火种生成的火池 | 关卡固定预设 / 种子播种 | **永久**（只能被反应顶掉） | 暖红火苗 |
| **环境·电** | 废土漏电桩 / 电种生成的电源 | 关卡固定预设 / 种子播种 | **永久** | 蓝白电弧 |
| **环境·冰** | 干冰排气孔 / 冰种生成的冰面 | 关卡固定预设 / 种子播种 | **永久** | 白霜颗粒 |
| **环境·植物** | 枯萎荆棘丛 / 植物种子 | 关卡固定预设 / 种子播种 | 永久，遇火则燎原烧尽 | 灰绿倒刺 |

### 为什么"获取方式"必须分层？

水和土是**可再生**的（跑一趟就有），所以玩家敢大面积铺。
种子是**不可再生**的（只有波前配给与精英怪掉落两条来源，掉落还是 4 种等权随机），所以每一次播种都是一次承诺：

> "这里是我接下来 30 秒要守的地方。"

## 五、种子基建：玩家即环境创造者

种子**不是消耗性弹药**，是**便携式环境发生器**（Portable Environmental Anchors）。

| 种子 | 生成的设施 | 与【水】联动 | 与【土】联动 | 战术定位 |
| --- | --- | --- | --- | --- |
| **火种子** | 基础火池 | → 蒸汽（伤害爆发） | → 陶砖（阻挡矮墙） | 伤害爆发区 |
| **电种子** | 基础电源 | → 导电区（**全网泛洪**） | → 陶砖（顺手筑墙） | 连锁陷阱中枢 |
| **冰种子** | 基础冰面 | → 结冰 | → 结冰 | 溜怪 / 控速跑道 |
| **植物种子** | 基础花 | → 基础植物区（浇成植物区后**再**浇纯水 → 普通泥浆 ×0.5 减速） | → 陶砖 | 易燃陷阱底料 |

> 上表只给"联动出什么地貌"，**每一次联动的瞬伤 / 击退 / 麻痹数值不在本节重复**，一律看 §6.1 的一级反应表（该表与 `element_rule.xlsx` 逐行一致；表里另有本表未重复的 `impact_radius` 一列）。

### 配给制（战略稀缺性）

- **主渠道 · 波前战术配给**：每个波次的**备战期开始**，直接发放该波配给的种子
  （`wave.grant_seed` 列：W1~W3 无配给（`None`），W4 / W5 / W6 配给火种子（`Fire`））。
  **尚未落地的设计意图**：电 / 冰种子也进波前配给 —— 表里没有任何 `Elec` / `Ice` 配给行。
- **应急渠道 · 精英怪战利品**：击杀 `enemy` 表 id=2（精英怪，6 血）必掉 **1 颗随机种子**
  （`enemy_drop.xlsx`：4 行、每行 `probability = 1`、`weight = 25` ⇒ 火 / 电 / 冰 / 植物等权；由 `CombatRoot.TryRollDrop` 抽）。

| 电 × 植物 | **带电荆棘** | 结果落格变成带电荆棘（可燃，会被下一次火连锁立刻烧成火海）。踩上去**每格麻痹 1.5 秒**（`tile_state.touch_stun`） |
| 冰 × 火 | **热应力白雾** | 结果落格回到空地。**`break_aggro = True`：范围内敌人清仇恨**；`effect_radius` 铺空地，只在临时地貌上生效，永久地貌不动 |

### 6.4 网格连锁引擎（`TileChainReactor`）

| 规则 | 值 | 为什么 |
| --- | --- | --- |
| 泛洪步数上限 | **128 格**（`MaxChainSteps`） | 环状水网会无限扩散；超限截断并只告警一次 |
| 邻接口径 | **四邻接**（上下左右） | 斜角相连的两片水在画面上并不连通，走八邻会"隔空导电" |

## 七、关卡波次推进模型

**严格的三阶段时钟**（`wave.xlsx` 每行的 `prep_time` / `battle_time` / `settle_time` 三列）。
**一个关卡打哪几波由 `level_wave.wave_ids` 给出**（列表列，顺序读取、可重复）：`WavePlayMode.Sequential` 跑完本关最后一行就进胜利结算；`WavePlayMode.Loop` 才回第一行无限轮转（`LevelReader._wavePlayMode` 默认 `Sequential`）。

└───────────────────────────┬──────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────┐
│ 2. 战斗期 (Battle · 20~60s) ──【核心体验：引怪入局与应急操作】 │
│  · 按 spawn_interval 逐只刷怪（同帧不补刷，掉帧只影响这一只）  │
│  · 见证连锁：怪物踩进电水线 → 全网麻痹                        │

### 8.3 列名 → 语义速查（填表前必读）

| 列 | 单位 / 取值 | 坑 |
| --- | --- | --- |
| `tile_state.slow_rate` | 倍率，1 = 不减速 | 消费者按物理帧续命；**小于 1 才会下发**（`TableTileState` 里就是 `if (SlowRate < 1f)`），填 1.0 表示不产生减速效果 |
| `tile_state.duration` | 秒；`-1` = 永久 | **只有 `> 0` 才计时**（`if (_duration > 0f)` 才累加 `_elapsed`），所以填 `0` 与填 `-1` 等效 = 永不到期；`durationOverride` 也只认 `> 0` |
| `tile_state.dot_damage` | 整数，每秒伤害 | 进格那一下由 `GridLogic.OnActorEnterCell` 补首跳，之后按 1 秒攒拍（掉帧会按次数补齐） |
| `tile_state.touch_stun` | 秒，踩上去的麻痹时长（`float`） | 现在只有 `带电荆棘` 填 1.5，其余 16 行是 0；消费点 `GridLogic.TouchStunOf`（`Assets/Scripts/Logic/Grid/GridLogic.cs:165`）→ `TileChainReactor.Propagate` / `SpreadFlameStep` |
| `element_rule.impact_damage` | 整数 | **落地当帧结算**，不是 DoT |
| `element_rule.impact_knockback` | 格 | 对敌人：`EnemyActor` 用 `v0 = √(2 × 受击减速度 × 格数 × 格边长)` 反解初速，所以"总位移 ≈ 填的格数"，不是加一个固定冲量。**玩家侧不读这个数** —— 玩家受击初速来自 `player.knockback_impulse` / `knockback_speed_limit` |
| `element_rule.trigger_chain` | bool | 真 = 落地后触发网格泛洪；走向由**结果地貌**决定（可燃/火海 → 燎原；导通 → 导电）。产物两样都不是就别填真 —— 泛洪的起点自己也必须导通 |
| `element_duo_reaction.result_duration` | 秒；`<=0` 时退回结果状态自己的 duration | 冰 × 电填 4s 是"超导存续"，不是"结冰存续" |
| `element_duo_reaction.effect_radius` | 格，欧氏距离 | **波及伤害 / 击退 + 铺场地区域**（`SpreadTileInRadius`）；1.5 覆盖 3×3、2.5 覆盖 5×5。**只铺在临时地貌上，永久地貌不动** —— 免得二级反应抹掉玩家铺的水 / 土 |
| `wave.spawn_interval` | 秒，下限 0.05（`WaveLogic.MinSpawnInterval`） | 0 会在同帧把整波刷爆 |
| `seed.spawn_tile` | TileStateType | 必须在 `tile_state` 里有行，否则播下去是空地 |
