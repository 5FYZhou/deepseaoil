# 玩家反馈原始记录

> 本目录保存玩家反馈原文的 Markdown 转写，仅供后续共同整理、过滤和转译。  
> 本层不做需求合并、优先级判断、技术方案或验收设计。

## 转写规则

- 保留发言者、原句、消息顺序、语气和主要分段。
- 不改写玩家错别字与口语表达。
- 只删除平台控件、截图缩略图、图片占位、无关寒暄和明确不承载反馈信息的插话。
- 同一玩家的连续发言尽量合并在同一文件；不同来源分别建档。
