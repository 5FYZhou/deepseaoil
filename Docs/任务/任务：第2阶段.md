# 任务二：连锁伤害/麻痹从 `tile_state` 读（"一体"语义）

## 背景

用户决策：**连锁时的伤害和麻痹应被视为该地貌自身属性的一体两面**，不再有独立的"链锁伤害"常量。

- 连锁电击每格伤害 = 该格当前状态的 `dot_damage`
- 连锁电击每格麻痹 = 该格当前状态的 `touch_stun`

## 改动

### 2.1 `GridLogic` 加读口

```csharp
/// <summary>该格地貌的每秒伤害（dot_damage）；未登记返回 0</summary>
public int DotDamageOf(Vector3Int cell)
{
    TileStateType state = StateOf(cell);
    return _specs.TryGetValue(state, out TileStateSpec spec) ? spec.DotDamage : 0;
}

/// <summary>该格地貌的接触麻痹（touch_stun）；未登记返回 0</summary>
public float TouchStunOf(Vector3Int cell)
{
    TileStateType state = StateOf(cell);
    return _specs.TryGetValue(state, out TileStateSpec spec) ? spec.TouchStun : 0f;
}
```

**注意**：`TouchStunOf` 若阶段一已加，直接复用。

### 2.2 `TileChainReactor` 改造

**删除常量**：
- `ShockDamage`
- `ShockStunSeconds`
- `FlameDamage`

**`Propagate`（电泛洪）**：
```csharp
int damage = grid.DotDamageOf(current);
float stun = grid.TouchStunOf(current);

// 兜底：地貌没配 dot_damage 时至少给 1 点（否则"电泛洪"变成 0 伤害）
if (damage <= 0) damage = 1;

grid.ApplyInstantShock(current, damage, stun);
```

**`SpreadFlameStep`（火海蔓延）**：
```csharp
int damage = grid.DotDamageOf(cell);
if (damage <= 0) damage = 1;

float stun = grid.TouchStunOf(cell);

grid.ApplyInstantShock(cell, damage, stun);
```

**"兜底 1"的理由**：地貌若被策划改成 `dot_damage = 0`（比如导电区改成"只麻痹不掉血"），链锁不应变成 0 伤害。但 `1` 是硬编码的语义决定——写注释说明。

**替代方案**：如果用户希望"配置说了算，0 就是 0"，则删掉兜底。Agent 在报告里**列出这个取舍**，让用户拍。

### 2.3 `CommitDuo` 里的 `PullStrength` / `MinBlastRadius`

- **删** `MinBlastRadius` 常量（`min_radius` 列已确认冗余）
- **删** `PullStrength` 常量，改为读 `duo.PullStrength`（来自表）
- **删** 白雾/超导的"半径 > 1.5 才生效"判据，改为读 `duo.BreakAggro`

**新 `CommitDuo` 结构**（供参考，实际按现有代码调整）：
```csharp
private static void CommitDuo(GridLogic grid, Vector3Int origin, DuoReactionSpec duo)
{
    if (grid.StateOf(origin) != duo.ResultTile)
    {
        grid.SwitchTileState(origin, duo.ResultTile, duo.ResultDuration);
    }

    float radius = duo.EffectRadius;

    grid.SpreadTileInRadius(origin, radius, duo.ResultTile, duo.ResultDuration);
    grid.ApplyBlast(origin, radius, duo.ImpactDamage, duo.ImpactKnockback);

    if (duo.PullStrength > 0f) PullInRadius(grid, origin, radius, duo.PullStrength);
    if (duo.BreakAggro) BreakAggroInRadius(grid, origin, radius);

    if (!duo.TriggerChain) return;
    // ... 后续不变
}
```

## 验收

- 改 `tile_state.dot_damage` 后，DoT 与连锁伤害同时变
- 改 `tile_state.touch_stun` 后，连锁麻痹跟着变
- 改 `element_duo_reaction.pull_strength` 后，超导吸力跟着变
- 改 `element_duo_reaction.break_aggro` 后，白雾清不清仇恨跟着变

## 4.3 合并规则（`TryGet` 核心逻辑）

**首次调用时构建缓存**（`Dictionary<int, EnemyTuningEntry>`），之后 O(1)：

```csharp
private EnemyTuningEntry Merge(EnemyTuningEntry entry, EnemyTuningEntry def)
{
    // 每个字段：entry 的值 > 0 用自己的，否则用 defaultEntry 的
    return new EnemyTuningEntry
    {
        id = entry.id,
        radius = entry.radius > 0f ? entry.radius : def.radius,
        acceleration = entry.acceleration > 0f ? entry.acceleration : def.acceleration,
        knockbackDecay = entry.knockbackDecay > 0f ? entry.knockbackDecay : def.knockbackDecay,
        stopDistance = entry.stopDistance > 0f ? entry.stopDistance : def.stopDistance,
        chaseRange = entry.chaseRange > 0f ? entry.chaseRange : def.chaseRange,
        visionRange = entry.visionRange > 0f ? entry.visionRange : def.visionRange,
        sustainRange = entry.sustainRange > 0f ? entry.sustainRange : def.sustainRange,
        loseDelay = entry.loseDelay > 0f ? entry.loseDelay : def.loseDelay,
    };
}
```

**注意**：合并后的值是**新实例**，不复用 `entries` 里的原始实例（避免污染用户填的 Inspector 值）。

**`TryGet` 逻辑**：
1. 首次调用时构建缓存：对每个 `entries[i]` 做 `Merge(entries[i], defaultEntry)`
2. 后续 O(1) 查缓存
3. id 无匹配 → 返回 `Merge(defaultEntry, defaultEntry)`（即纯 default）
4. **警告**：首次未命中打一次（阶段一已实现），保持

**关键**：`defaultEntry` 自身也可能有字段为 0（用户没填）。**合并后为 0 的字段沿用代码硬编码默认值吗？**
- **不沿用**。规则是"entry 有值就 entry，否则 default"；default 也为 0 时返回 0，由消费侧处理
- 消费侧（`EnemySpec`）对 0 值**不做兜底**：`AggroState` 收到 `visionRange = 0` 意味着"永不获得仇恨"（`sqrDist <= 0` 恒 false），这是配置事故
- **但**用户会填 `defaultEntry` 的值（手工清单里说明）；未填属于配置错误
