> # 四、`HopDriver`（新增）
>
> 路径：`Presentation/Effects/Drivers/HopDriver.cs`，命名空间 `DeepseaOil.Presentation.Effects.Drivers`。
>
> ## 4.1 骨架
>
> ```
> public sealed class HopDriver : IEffectDriver
> {
>     private sealed class HopState
>     {
>         public Transform Target;
>         public float BaseY;       // 首次抓取时的 localPosition.y
>         public float Elapsed;
>         public float Duration;
>         public float Peak;        // hopPeakHeight × Value
>         public int HandleId;
>     }
> 
>     private readonly Dictionary<Transform, HopState> _states = new();
>     private readonly List<Transform> _recycleScratch = new();
>     private readonly int _maxSize;
>     private int _nextId;
>     private int _epoch = 1;
>     private bool _disposed;
> 
>     internal HopDriver(in EffectSpec spec) : this(spec.MaxSize) { }
>     public HopDriver(int maxSize = 32) { ... }
> }
> ```
>
> ## 4.2 契约
>
> | 项                    | 值                                 |
> | --------------------- | ---------------------------------- |
> | `AssetKey`            | `string.Empty`（程序型，不查资源） |
> | `IsAssetReady`        | `true`                             |
> | `IsSingleton`         | `false`                            |
> | `OnAssetLoaded`       | 空实现                             |
> | `ActiveInstanceCount` | `_states.Count`                    |
> | `PooledObjectCount`   | `0`                                |
>
> ## 4.3 `Play(id, ctx)`
>
> 1. `_disposed` → `None`
> 2. `ctx.Anchor == null` → `None`（**锚点必填**）
> 3. `ctx.Value` 为 `NaN` / `Infinity` / `≤0` → `None`（**不 clamp 上限**，只拦非法值）
> 4. 从 `ConfigModule.VisualFeel` 读 `hopPeakHeight` / `hopDuration`
> 5. `Duration = ctx.Duration > 0 ? ctx.Duration : VisualFeel.hopDuration`
> 6. `Peak = VisualFeel.hopPeakHeight * ctx.Value`
> 7. 目标已在 `_states` → **重置**（`Elapsed = 0` / `Duration` / `Peak` 覆盖；`BaseY` 不动）；否则新建（`BaseY = Anchor.localPosition.y`）
> 8. 超 `_maxSize` → `WarnPoolFull`（节流，参照 `ScalePunchDriver`）→ `None`
> 9. `HandleId = ++_nextId`；`ApplyAt(state, 0f)`；返回 `EffectHandle`
>
> ## 4.4 `Tick(dt)`
>
> 遍历 `_states`：
> - `Target == null`（Unity 假 null）→ 摘账
> - `Elapsed += dt`
> - `t = Duration > 0 ? Elapsed / Duration : 1f`
> - `t >= 1` → 还原 `Target.localPosition.y = BaseY`；摘账
> - 否则 `ApplyAt(state, t)`
>
> 回收走 `_recycleScratch` 二次遍历（**foreach 期间不改字典**）。
>
> ## 4.5 `ApplyAt(state, t)`
>
> ```
> float arc = Ballistics.ArcHeight01(Mathf.Clamp01(t));
> Vector3 p = state.Target.localPosition;
> p.y = state.BaseY + state.Peak * arc;
> state.Target.localPosition = p;
> ```
>
> **只改 `y`**：`x` / `z` 原样写回。
>
> ## 4.6 `Stop` / `CleanAll` / `Dispose`
>
> - `Stop(handle)`：代次校验；命中则还原 `BaseY` 并摘账
> - `CleanAll`：`_epoch++`；全量还原 + 清账
> - `Dispose`：`CleanAll()`；`_disposed = true`
>
> 参照 `ScalePunchDriver` 的对应方法；不引入新写法。
>
> ## 4.7 注释
>
> `/// <summary>击退伪高度：Anchor.localPosition.y 抬一次抛物线再归零</summary>`
>
> `/// <remarks>只写 localPosition.y，不碰 Root 与 localScale；与 ScalePunchDriver 同帧不冲突（不同轴）。Value 语义 = v0 / hopReferenceSpeed，NaN/Inf/≤0 拒播，不 clamp 上限。</remarks>`
>
