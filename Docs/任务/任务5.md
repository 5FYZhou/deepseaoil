> # 六、`ActorTintDriver` 加 AlphaTint 第三通道
>
> ## 6.1 `ColorState` 加字段
>
> ```
> public bool AlphaOn;
> public int AlphaHandleId;
> public ActorAnimationView AlphaSource;   // 直接依赖（同层 Presentation）
> ```
>
> ## 6.2 `Play` 分支
>
> 在现有 `else if (id == EffectId.SlowTint)` 之后加 `else if (id == EffectId.AlphaTint)`：
>
> 1. `ctx.Anchor == null` → `None`
> 2. `AlphaSource = ctx.Anchor.GetComponentInParent<ActorAnimationView>()`（**不往下探**，只往父级找；找不到则 `AlphaSource = null`）
> 3. `state.AlphaOn = true`；`state.AlphaHandleId = ++_nextId`
> 4. `ApplyPersistentTint(state)`（立即写一次）
> 5. 返回 `new EffectHandle(state.AlphaHandleId, _epoch, this)`
>
> **重复 Play 时**：`AlphaOn == true` 且 `AlphaSource` 相同 → 复用旧句柄，不重置（幂等）。
>
> ## 6.3 `Tick` 里合并写
>
> 现有 `Tick` 里对每个 `state`：
> - 若 `AlphaOn && state.AlphaSource != null`：读 `AlphaSource.FadeAlpha`，与 `PersistentTint` 的 RGB 合并一次写 `renderer.color`
> - 若 `AlphaOn && state.AlphaSource == null`：`a = 1`（保持不透明）
>
> **与慢速垫色（`SlowTint`）正交**：RGB 由 `PersistentTint` 管，alpha 由本通道独占；**只写一次 `renderer.color`**。
>
> ## 6.4 `ApplyPersistentTint` 改造
>
> 现有 `ApplyPersistentTint(state)` 只写 RGB。改为：
>
> ```
> Color final = state.PersistentTint * state.BaseColor;
> final.a = state.BaseColor.a * (state.AlphaOn && state.AlphaSource != null
>     ? state.AlphaSource.FadeAlpha
>     : 1f);
> state.Renderer.color = final;
> ```
>
> **BaseColor.a 保留美术基线 alpha**，本通道只乘一次系数。
>
> ## 6.5 `Stop` 分支
>
> 在 `Stop(handle)` 现有 `SlowTint` 匹配后，加 `AlphaTint` 匹配：
>
> - `state.AlphaOn = false; state.AlphaHandleId = 0; state.AlphaSource = null;`
> - `ApplyPersistentTint(state)` 还原（`a = BaseColor.a`）
>
> ## 6.6 `CleanAll` / `Dispose`
>
> 现有实现已全量还原，**不改**——但确认 `ApplyPersistentTint` 里的 `AlphaOn` 逻辑能在 `CleanAll` 路径下把 alpha 还原到 `BaseColor.a`。
>

> # 七、`EnemyActor.Die` 重构
>
> ## 7.1 `Die` 新流程
>
> `Die(direction)` 改为：
>
> ```
> if (_deathFired) return;
> _deathFired = true;
> 
> if (_motor != null) _motor.Move(Vector2.zero);
> 
> if (_registry != null && _registered) { _registry.Unregister(this); _registered = false; }
> 
> if (!_deathFired 已发过) ...  // _deathFired 已守卫，此处直接
> Died?.Invoke(this);   // 掉落同帧（现有 _deathFired 守卫后再发）
> 
> if (_collider != null) _collider.enabled = false;
> 
> _animView?.TriggerDie();
> 
> // 增强层（原 Shatter）
> EffectContext shatter = EffectContext.At(Position, hitDirection);
> shatter.Tint = ConfigModule.Visuals.enemyBodyNormal;
> shatter.Value = ConfigModule.VisualFeel.shatterIntensity;
> EffectModule.Play(deathEffect, in shatter);
> 
> // 尸体淡出
> if (_animView != null)
> {
>     EffectContext fade = EffectContext.OnTarget(_animView.transform);
>     _fadeHandle = EffectModule.Play(EffectId.AlphaTint, in fade);
> }
> 
> // T2 触发口
> if (_animView != null && _animView.HasValidAnimator)
> {
>     _animView.DeathAnimationEnd += OnDeathAnimationDone;
> }
> else
> {
>     StartCoroutine(CoFallbackDeath(ConfigModule.VisualFeel.deathFallbackSeconds));
> }
> ```
>
> **注**：现有 `Die` 里 `_deathFired = true; Died?.Invoke(this);` 的顺序**保持**（掉落要用位置）。`Motor.Move(zero)` 与 registry 摘账的**顺序与现有实现一致**（现场核对；如现有是先 registry 再 Motor，就按现有；本任务书不强制顺序，只强制"两者都在 Died 之前"）。
>
> ## 7.2 `OnDeathAnimationDone`
>
> 新增方法：
>
> ```
> private void OnDeathAnimationDone()
> {
>     if (_animView != null) _animView.DeathAnimationEnd -= OnDeathAnimationDone;
> 
>     if (IsScenePlaced && respawnDelay > 0f)
>     {
>         _respawnRoutine = StartCoroutine(CoRespawn());
>         return;
>     }
> 
>     Destroy(gameObject);
> }
> ```
>
> ## 7.3 `CoFallbackDeath`
>
> 新增协程：
>
> ```
> private System.Collections.IEnumerator CoFallbackDeath(float seconds)
> {
>     yield return new WaitForSeconds(seconds);
>     OnDeathAnimationDone();
> }
> ```
>
> **注意**：`CoFallbackDeath` 里不显式退订——`OnDeathAnimationDone` 里已有幂等退订（`-=` 对未订阅也安全）。
>
> ## 7.4 `TriggerDie` 去重
>
> 现有 `TakeDamage` 里 `if (!Stats.IsAlive) { _animView?.TriggerDie(); Die(damage.Direction); return; }`——**删掉 `_animView?.TriggerDie();`**，只留 `Die(...)`。
>
> 核对 `grep -rn "TriggerDie" Assets/Scripts` → 只应有 `Die` 内一处 + `ActorAnimationView` 定义。
>
> ## 7.5 `ResetToSpawn` 补退订与句柄清理
>
> 在 `ResetToSpawn` 开头加：
>
> ```
> if (_animView != null) _animView.DeathAnimationEnd -= OnDeathAnimationDone;
> if (_fadeHandle.IsValid) { EffectModule.Stop(_fadeHandle); _fadeHandle = EffectHandle.None; }
> ```
>
> 现有 `_animView.ResetToDefault()` 保留（`Rebind` 会回 `FadeAlpha` 默认）。
>
> ## 7.6 新字段
>
> `EnemyActor` 加：
>
> ```
> private EffectHandle _fadeHandle;
> ```
>
> 位置：现有 `_slowTintHandle` 附近。
>
> ## 7.7 `CoRespawn` 保持不变
>
> 现有 `CoRespawn`（`_body.enabled = false` → `WaitForSeconds(respawnDelay)` → `ResetToSpawn`）**不改**。若其中还引用 `hpText`（批 1 应已删），核对后无残留。
