> # 三、任务分解
>
> ## 步骤 1 · 物理迁移
>
> 目标目录：`Assets/Scripts/Data/Settings/`（若不存在则创建，含 `.meta`）。
>
> 对每个需移动的文件：
>
> ```
> git mv <src_path> Assets/Scripts/Data/Settings/<file>.cs
> git mv <src_path>.meta Assets/Scripts/Data/Settings/<file>.cs.meta
> ```
>
> 例外：`CombatFeelTuning.cs` → `VisualFeelTuning.cs`（文件名与类名同步改）。
>
> ## 步骤 2 · 命名空间
>
> 每个被迁文件的 `namespace DeepseaOil.Data` → `namespace DeepseaOil.Data.Settings`。
>
> 文件内若有 `using DeepseaOil.Data;`，先判断是否仍被自身用到（如引用 `ResourceKind` / `DropType`）：
> - 仍用 → 保留
> - 不用 → 删掉那一行 `using`
>
> ## 步骤 3 · 类改名
>
> 全局替换 `CombatFeelTuning` → `VisualFeelTuning`（含：
> - 类声明
> - `class` / `const` / `static` 修饰的成员引用
> - `CreateInstance<...>` / `Load<...>` / `LoadOrDefault` 返回类型
> - 注释里的提及（注释里的类名属于契约，**同步改**）
>
> ## 步骤 4 · 资源 Key
>
> `VisualFeelTuning.cs` 里的常量值：
>
> `ResourceKey = "tuning/CombatFeelTuning"` → `ResourceKey = "tuning/VisualFeelTuning"`
>
> **这是最容易漏的一条**：`.asset` 文件已被用户重命名为 `VisualFeelTuning.asset`；字符串不改，运行期 `AssetModule.Load` 直接失败、静默走字段默认值。
>
> 核对一遍全仓：`grep -rn "tuning/CombatFeelTuning"` 应**零命中**。
>
> ## 步骤 5 · ConfigModule 引用改名
>
> `Assets/Scripts/Data/Config/ConfigModule.cs`：
>
> | 原                                          | 新                                          |
> | ------------------------------------------- | ------------------------------------------- |
> | `private static CombatFeelTuning _feel;`    | `private static VisualFeelTuning _feel;`    |
> | `public static CombatFeelTuning Feel`       | `public static VisualFeelTuning VisualFeel` |
> | `_feel = CombatFeelTuning.LoadOrDefault();` | `_feel = VisualFeelTuning.LoadOrDefault();` |
> | 文件顶部 `using`                            | 加 `using DeepseaOil.Data.Settings;`        |
>
> ## 步骤 6 · 引用点同步
>
> 全仓扫：
>
> - `grep -rn "CombatFeelTuning" Assets/Scripts` → 应零命中（除报告）
> - `grep -rn "\.Feel\b" Assets/Scripts` → 逐条判；只改 `ConfigModule.Feel` 形式的，改 `ConfigModule.VisualFeel`
> - `grep -rn "namespace DeepseaOil.Data\b" Assets/Scripts/Data` → 应只剩未迁的（`Config/` / `Asset/` / `Metrics/` 下）
>
> 所有引用这些类的文件（`EnemyActor.cs` / `PlayerController.cs` / `CombatRoot.cs` / `EnemySpec.cs` / `PlayerSpec.cs` / `ProjectileSpec.cs` / `DropSpec.cs` / `AudioManager.cs` / `ActorLogic.cs` / `ActorMotor.cs` 等，现场扫）：
>
> - 若已 `using DeepseaOil.Data;` 且这些类**只在这一个 using 下可见** → 加 `using DeepseaOil.Data.Settings;`
> - 若文件用全限定名 `DeepseaOil.Data.PlayerConfig` → 改 `DeepseaOil.Data.Settings.PlayerConfig`
>
