## 背景：为什么改

现在 `TilemapAdapter` 只有**一个** `effectTilemap`，整层共用一个材质。Unity 的 Tilemap 不支持 per-tile 材质，所以"火要动、水不动"无法实现。

解法：**按动效组拆多个 Tilemap**，每层一个材质。状态到层的映射是静态配置。

目标结构（用户会在场景里手工搭）：

```
Grid
├── Ground              Order 0   地板
├── InitialSetup        Order 1   关卡编辑层
├── TileEffect_Static   Order 2   泥浆 / 水 / 土 / 陶砖 / 冰面 / 导电区 / 荆棘 / 冰刺
├── TileEffect_Fire     Order 3   火池 / 火海
├── TileEffect_Water    Order 4   基础水（可选）
└── TileEffect_Steam    Order 5   蒸汽
```

## 任务一：数据结构

### 1.1 新增 `EffectLayerBinding`

在 `TilemapAdapter` 内部（或同文件同级）新增：

```csharp
[Serializable]
public struct EffectLayerBinding
{
    [Tooltip("这一层的 Tilemap。同一格的状态贴图只画在它归属的那一层里")]
    public Tilemap Tilemap;

    [Tooltip("这一层负责哪些状态；同一状态只能出现在一层。留空 = 只作兜底层，不主动接状态")]
    public TileStateType[] States;
}
```

### 1.2 字段替换

- **删除** `[SerializeField] private Tilemap effectTilemap = default;`
- **新增** `[SerializeField] private EffectLayerBinding[] effectLayers = new EffectLayerBinding[0];`
- **新增** `[Tooltip("未在任何层显式登记的状态落到哪一层。默认取 effectLayers[0]")] [SerializeField] private Tilemap fallbackEffectTilemap = default;`（可选，留空则用数组第一项）

`stateTiles` / `groundTilemap` / `initialSetupTilemap` **不动**。

### 1.3 预建映射

在 `Awake` 里（或 `Initialize` 里）建一次：

```csharp
// state → tilemap
private readonly Dictionary<TileStateType, Tilemap> _stateToLayer = new Dictionary<TileStateType, Tilemap>();
```

遍历 `effectLayers`：
- 每层的 `Tilemap` 为 null → 报错跳过该层
- 每层 `States` 里的状态加进映射；**重复状态报错**（哪个状态、哪两层）
- `fallbackEffectTilemap` 与 `effectLayers[0].Tilemap` 都为空 → 报错（无层可用）

## 任务二：分发逻辑

### 2.1 `OnTileStateChanged` 改造

现在的逻辑（单层）：
```
if State == Normal → Restore(cell)
else → Show(cell, TileFor(State))
```

改成：
```
1. 从所有层擦除该格的旧 tile（逐个 effectLayers[i].Tilemap.SetTile(cell, null) 或 SetTile(cell, 原始 tile)，看 §2.3）
2. if State == Normal → 结束
3. 查 _stateToLayer[State] → 目标层
4. 查不到 → fallbackEffectTilemap
5. 目标层为空 → 打一次警告并返回（不要每帧刷）
6. 目标层.SetTile(cell, TileFor(State))
```

### 2.2 `Show` / `Restore` 语义

**删除**这两个方法（其逻辑并入 `OnTileStateChanged`），或改造成"针对某一层的写入"。选实现最简单的。

### 2.3 `_previousTiles` 缓存：唯一易翻车点

**现状**：`_previousTiles[cell]` 记录该格原本在 effectTilemap 上的 tile（用于状态结束时还原）。效果层开局是空的，所以原值通常是 null。

**改多层后**：某格可能在任意层上被写过 tile。擦除时不能只擦"它现在归属的层"，要**擦遍所有层** —— 否则某状态曾在 A 层、现在切到 B 层，A 层会残留。

**方案选择**（选一个，写清理由）：

| 方案                    | 实现                                                  | 取舍                                       |
| :---------------------- | :---------------------------------------------------- | :----------------------------------------- |
| **甲 · 记录当前所在层** | 每格只记 `_cellLayer[cell] = 层`，擦除时对该层写 null | 简单；前提是效果层开局全空（当前就是这样） |
| **乙 · 记录每层原值**   | 每格每层记一份原值                                    | 通用；但效果层开局空，收益低               |

**推荐甲**，并在注释里写明"前提：效果层开局全空；若将来效果层被手工刷过 tile，改乙"。

具体：
- 删 `Dictionary<Vector3Int, TileBase> _previousTiles`
- 加 `Dictionary<Vector3Int, Tilemap> _cellLayer`（记录该格当前在哪个效果层）
- `OnTileStateChanged` 先查 `_cellLayer` → 从该层擦除 → 再加到新层 → 更新 `_cellLayer[cell]`
- `Normal` 时擦除并 `_cellLayer.Remove(cell)`

### B. Shader Graph 与材质

做一份 `M_TileFlow` 基础 Shader Graph（走 `Sprite-Lit-Default` 兼容 2D Lighting）：

**暴露参数**：

| 参数             | 类型  | 用途        |
| :--------------- | :---- | :---------- |
| `_FlowSpeed`     | Float | 扰动速度    |
| `_FlowAmplitude` | Float | UV 偏移幅度 |
| `_FlowFrequency` | Float | 扰动频率    |

**节点骨架**：

```
UV ─┬─→ Add ─→ Sample Texture 2D ─→ Output
    │      ↑
    └── Sine(Time * _FlowSpeed + UV.y * _FlowFrequency) * _FlowAmplitude
       （同时叠一层 UV.x 方向的相位不同的 Sine，避免"整层平移"）
```

**每层的材质实例推荐值**：

| 材质               | Speed | Amplitude | Frequency |
| :----------------- | :---- | :-------- | :-------- |
| `M_TileFlow_Fire`  | 3.0   | 0.012     | 20        |
| `M_TileFlow_Water` | 1.2   | 0.008     | 8         |
| `M_TileFlow_Steam` | 0.6   | 0.015     | 12        |

**硬性约束**：
- `Amplitude ≤ 0.02`：超过会采到贴图边缘外
- 贴图边缘留 **2~4 像素透明 padding**（否则扰动时边缘会采到图外像素色）
- 材质必须挂在 **`TilemapRenderer.Material`** 上（不是某个 Tile 资产上）
