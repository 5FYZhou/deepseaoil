- **Shader**：`DeepseaOil/Particles/ProceduralLightning`（使用你提供的 Shader）
- **参数推荐**：

### 四、夜间全场景弥漫粒子迁移方案 (Night Ambient Fireflies)

把之前的萤火虫资产优雅地收拢为全图黑夜氛围：

1. **预制体迁移**：
   - 将原 `Vfx_Tile_Electricity` 另存为 `Assets/Resources/effects/Vfx_Ambient_NightFireflies.prefab`；
   - 形状改为全屏大范围：
     - `Shape = Box`，`Box X = 20, Box Y = 12`（覆盖主相机视野）；
     - `Simulation Space = World`；
     - `Rate over Time = 12 ~ 16`；
     - `Velocity Orbital Z = 0.5`（极为缓慢悠闲的浮游）。
2. **生命周期联动**：
   - `EnvironmentDirector` 在切换到 `Night` 时，自动 `SetActive(true)` 打开该粒子；切换到 `Day` 时渐隐或关闭。
   - 这样原有的心血完全没有浪费，反而变成了极大提升夜景氛围的高级视觉点缀！
