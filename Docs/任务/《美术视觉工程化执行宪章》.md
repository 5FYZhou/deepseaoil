### (Art & Visual Engineering Execution Charter)

## 一、宪章定位与第一性工程原则

1. **绝对禁止项（工程红线）**：
   - **禁止 PBR 材质与法线贴图**：全仓严禁引入 Normal Map，严禁尝试 3D 物理高光与金属度衰减。
   - **禁止暗部纯黑（No Pitch-Black）**：环境光下限（Ambient Floor）强制锁定在 $\ge 0.35$，严禁任何物体因受光衰减跌入死黑发脏。
   - **禁止荧光与大范围高斯光雾**：Bloom 阈值强制锁死在 $\ge 1.1$，严禁全屏漫反射发光，保证色块画风的硬朗与干净。
2. **材质通道分流铁律**：
   - **实体与地貌（Cel-Lit）**：角色真身、地块、道具走轻量赛璐珞着色模型，接受环境光色相微调。
   - **特效与战斗反馈（100% Unlit）**：粒子、弹幕、飘字、蒸汽、电弧、闪白、UI **绝对不接受任何光照衰减**，素材颜色即最终呈现色。

## 四、材质、伪高度与受光表现契约

针对美术提出的“无高度图实现伪高度”与“禁止 PBR”，确立以下技术实现边界：

### 1. 材质着色器矩阵 (Shader Matrix)

```text
                    ┌─────────────────────────────────────────┐
                    │            全仓 Shader 分流             │
                    └────────────────────┬────────────────────┘
                                         │
                 ┌───────────────────────┼────────────────────────┐
                 ▼                       ▼                        ▼
       【Cel-Lit 漫反射型】       【Unlit 绝对自发光型】     【特殊程序化型】
       Sprite-Lit / TileFlow      SpriteFlash (材质插值)     ProceduralEmber (像素核)
       (地表瓦片/角色身体)        Particle (所有爆炸微粒)    ProceduralLightning (折角电)
       *受环境光与点光影响        DamagePopup (伤害跳字)     ProceduralSteam (FBM雾)
       *暗部有 0.35 保护底        *100% 免疫环境光衰减       *不受常规光照影响
```

### 2. 伪高度与立体感实现标准（彻底规避 Normal Map）
- **泥浆/稀泥“陷入感”**：
  - **严禁**写深度图或 Parallax Shader；
  - **标准解法**：`EnemyActor` / `PlayerController` 踏入泥浆地块时，逻辑层通知 `View.localPosition.y` 瞬时向下沉降 **0.08 世界单位**（约 8 像素），走出泥浆秒回弹，产生纯物理机械沉降感。
- **地貌高低差顶光边缘高光（Rim-Highlight）**：
  - 在地表 Shader 中提取贴图 Alpha 边缘与 UV 顶端（$UV.y > 0.92$）；
  - 叠加 1 像素宽的明亮黄色（`#F9CE5A`）边缘亮线，通过纯色块模拟顶光照射凸起边缘。
- **机械/金属强反光（禁止 PBR）**：
  - 采用 **赛璐珞阶梯函数（Step-Banding）**：通过片元颜色感知亮度计算高光掩码 `step(0.85, luminance)`；
  - 命中区域直接填入手绘高光硬块色（`Color.white`），无平滑过渡。

## 五、地块网格与高亮表现规范

1. **常态地面网格**：
   - 彻底隐藏/淡化网格线。地表由常规瓦片连续铺砌，不得显示任何黑色或深色棋盘格边框。
2. **鼠标悬停瞄准格（`TileHighlightView`）**：
   - **废除实心白方块**：彻底替换原有 `PrimitiveSprites.Square` 填充面；
   - **标准形式**：采用手绘黄色虚线/实线边框（外框宽 2 像素，颜色 `#F9CE5A`，Alpha 0.6）；
   - **外发光微动效**：边缘附带微弱外发光，以 2.0 Hz 频率在 Alpha 0.4 ~ 0.7 之间呼吸浮动。

## 七、后处理 (Global Volume) 封印参数

全场景仅允许存在一个挂载在 `Global Volume` 上的全局配置文件，参数阈值彻底封印如下：

| 后处理模块      | 参数字段     | 严格锁定值       | 设定理由与防炸依据                                           |
| :-------------- | :----------- | :--------------- | :----------------------------------------------------------- |
| **Bloom**       | `Threshold`  | **`1.15`**       | **核心保险**：必须高于 1.0，防止 0.12 秒受击纯白剪影（Flash）变成大白斑。 |
|                 | `Intensity`  | **`0.45`**       | 控制发光强度，仅允许电弧尖端和火核产生微弱赛璐珞光晕。       |
|                 | `Scatter`    | **`0.60`**       | 紧凑型散射，杜绝全屏弥漫光雾破坏手绘色块感。                 |
| **Vignette**    | `Color`      | `#1E1E1D` (深灰) | 严禁使用纯黑色压角，与美术 UI 深灰底色完全对齐。             |
|                 | `Intensity`  | **`0.22`**       | 轻微收拢视野，主要视觉留白给场景原画。                       |
|                 | `Smoothness` | **`0.40`**       | 柔和边缘羽化。                                               |
| **Tonemapping** | `Mode`       | **`Neutral`**    | **禁用 ACES**（ACES 会拉高对比度导致手绘原画暗部变脏），Neutral 保证原色最大忠实度。 |

## 八、验收判据与工程门禁 (Definition of Done)

所有美术管线任务验收时，必须同时满足以下客观指标：

- [ ] **色彩保真**：在白天光照（Intensity 0.75, `#FFF5DD`）下，场景地面色板采样误差与主色板相比，RGB 偏移量 $\le 8\%$，无发灰发脏现象。
- [ ] **闪白与 Bloom 兼容**：任何单位挨打闪白（0.12 秒）时，屏幕上能清晰看清角色剪影边缘，**无过曝融化成光球的现象**。
- [ ] **DrawCall 控制**：在包含 1 盏全局光 + 32 盏动态点光源（火池/电弧满载）的极端压力下，**DrawCall 增量 $\le 25$**（受光图层精准隔离）。
- [ ] **濒死视音频联动**：玩家血量跌至 1 时，全屏裂纹按 75 BPM 跳动，Audio 频谱 800Hz 以上高频被彻底切除，心跳低音凸显。
- [ ] **编译门全绿**：全仓代码与 Shader 变更保持 `pwsh Tools/compile-gate.ps1` **0 error / 0 warning**。
