# 任务三：二级反应铺地貌

## 目标
`element_duo_reaction.effect_radius` 从"只喂伤害/击退"变成"范围内也铺 `result_tile`"。

## 数据侧不需要动
表已就绪，`DuoReactionSpec` 已有 `ResultTile` / `EffectRadius`。

## 改动：`GridLogic.ApplyBlast`

**现状**：`ApplyBlast(center, radius, damage, knockback)` 只做伤害/击退。

**改为**：加一个可选参数，或在 `TileChainReactor.CommitDuo` 里另起一段。

**推荐后一种**（不改 `ApplyBlast` 签名，避免影响一级反应调用点）：

新增 `GridLogic.SpreadTileInRadius(Vector3Int center, float radiusCells, TileStateType resultTile)`：
- 遍历半径内格（复用 `_blastCells` 逻辑或独立缓冲）
- 对每格：
  - 若 `StateOf(cell) == resultTile` → 跳过（不重复改）
  - 若**该格当前状态是永久地貌（`Duration <= 0`）** → **跳过**（保护玩家铺的水/土/基建）
  - 否则 `SwitchTileState(cell, resultTile)`
- 半径口径与 `ApplyBlast` 一致（欧氏距离、含中心格）

**注意"永久地貌不覆盖"的判定**：需要 `TileStateSpec.Duration <= 0`。`GridLogic` 已有 `_specs` 字典，直接查。

## 改动：`TileChainReactor.CommitDuo`

**现状**：
```csharp
grid.SwitchTileState(origin, duo.ResultTile, duo.ResultDuration);
grid.ApplyBlast(origin, radius, duo.ImpactDamage, duo.ImpactKnockback);
```

**改为**（在 `ApplyBlast` 之后加一行）：
```csharp
grid.SpreadTileInRadius(origin, radius, duo.ResultTile);
```

**触发格自己**已有 `SwitchTileState(origin, ...)`，`SpreadTileInRadius` 里对 `origin` 自身的处理是"已经是 `resultTile`，跳过"，不冲突。

## 效果示例

- **超导**（冰 × 电 → 结冰，半径 2.5）：范围内 5×5 全部变结冰（除永久地貌）
- **白雾**（冰 × 火 → 空地，半径 2.5）：范围内 5×5 全部变空地（除永久地貌）

## 注意

- **`durationOverride`**：`CommitDuo` 用了 `duo.ResultDuration` 覆盖触发格。`SpreadTileInRadius` 是否也覆盖？
  - 建议**也覆盖**：一致的存续语义。
  - 若加参数嫌重，可用默认参数：`SpreadTileInRadius(center, radius, resultTile, durationOverride = 0f)`，调用方传 `duo.ResultDuration`。

**现状**：`SpreadFlameStep` 调用 `grid.ApplyInstantShock(cell, FlameDamage, 0f)` —— stun 硬编码 0。

```csharp
    return _specs.TryGetValue(state, out TileStateSpec spec) ? spec.TouchStun : 0f;
}
```


## 5.2 表现层：`TileObstacleDirector`

新建 `Assets/Scripts/Presentation/Grid/TileObstacleDirector.cs`。骨架照 `TileOverlayDirector`。

```csharp
public sealed class TileObstacleDirector : MonoBehaviour
{
    [SerializeField] private int maxPoolSize = 32;

    private readonly Dictionary<Vector3Int, GameObject> _active = new();
    private readonly HashSet<TileStateType> _obstacleStates = new();

    private Pool<GameObject> _pool;
    private GridGeometry _geometry;
    private bool _attached;

    public void Initialize(in GridGeometry geometry)
    {
        _geometry = geometry;

        _obstacleStates.Clear();
        IReadOnlyList<TileStateSpec> specs = ConfigModule.GetAllTileStates();
        for (int i = 0; i < specs.Count; i++)
        {
            if (specs[i].IsObstacle) _obstacleStates.Add(specs[i].Id);
        }

        _pool = new Pool<GameObject>(
            factory: CreateObstacleObject,
            onGet: go => go.SetActive(true),
            onRelease: go => go.SetActive(false),
            name: "TileObstaclePool",
            maxSize: maxPoolSize,
            overflowPolicy: PoolOverflowPolicy.CreateOrDrop,
            onDestroy: Destroy);
    }

    public void Attach() { EventBus<TileStateChanged>.Subscribe(OnTileStateChanged); _attached = true; }
    public void Detach() { ... Unsubscribe; ClearAll(); }

    public void ClearAll()
    {
        foreach (KeyValuePair<Vector3Int, GameObject> kv in _active)
        {
            if (kv.Value != null) _pool.Release(kv.Value);
        }
        _active.Clear();
    }

    private void OnDestroy() { Detach(); _pool?.Dispose(); _pool = null; }

    private void OnTileStateChanged(TileStateChanged evt)
    {
        // 先归还旧对象
        if (_active.TryGetValue(evt.Cell, out GameObject old))
        {
            _pool.Release(old);
            _active.Remove(evt.Cell);
        }

        if (!_obstacleStates.Contains(evt.State)) return;
        if (!_geometry.IsValid) return;

        if (!_pool.TryGet(out GameObject obj) || obj == null) return;

        Vector2 center = _geometry.CellCenter(evt.Cell);
        obj.transform.position = new Vector3(center.x, center.y, 0f);

        // 池对象池化配置时不重建 Collider，只在 CreateOverlayObject 里建一次
        // 大小由 Initialize 时按 _geometry.CellSize 设置 scale
        _active[evt.Cell] = obj;
    }

    private GameObject CreateObstacleObject()
    {
        var go = new GameObject("TileObstacle");
        go.transform.SetParent(transform, false);

        var box = go.AddComponent<BoxCollider2D>();
        box.size = Vector2.one * (_geometry.IsValid ? _geometry.CellSize : 1f);

        go.SetActive(false);
        return go;
    }
}
```

**注意**：`CreateObstacleObject` 里读 `_geometry.CellSize`。`_geometry` 在 `Initialize` 里赋值，`Pool.factory` 首次触发是 `TryGet` 时（`Initialize` 之后），所以赋值顺序没问题。

## 5.5 绕障集成：`EnemyLogic`

**新增字段**：
```csharp
private GridLogic _grid;                     // 可空：null = 无绕障
private readonly List<Vector3Int> _pathFrontier = new(32);
private readonly Queue<Vector3Int> _pathQueue = new(32);
private readonly HashSet<Vector3Int> _pathVisited = new(64);
private readonly Dictionary<Vector3Int, Vector3Int> _pathCameFrom = new(64);
private int _pathCooldown;
private Vector2 _pathDirection;
private const int PathRecalcFrames = 5;
```

**新增方法**：
```csharp
public void AttachGrid(GridLogic grid) { _grid = grid; }

/// <summary>绕障方向：直线可通行时返回原方向；被挡时返回 BFS 第一步；找不到时返回原方向（撞墙）</summary>
public Vector2 ResolveObstacle(Vector2 direction)
{
    if (_grid == null || !_grid.Geometry.IsValid) return direction;
    if (direction.sqrMagnitude <= 0f) return direction;

    if (_pathCooldown-- > 0) return _pathDirection.sqrMagnitude > 0f ? _pathDirection : direction;
    _pathCooldown = PathRecalcFrames;

    Vector3Int selfCell = _grid.WorldToCell(Motor.Position);
    Vector2 ahead = Motor.Position + direction.normalized * (_grid.Geometry.CellSize * 0.6f);
    Vector3Int aheadCell = _grid.WorldToCell(ahead);

    // 直线可达：不寻路
    if (!_grid.IsObstacle(aheadCell))
    {
        _pathDirection = direction;
        return direction;
    }

    // 目标格：从 _target 换算，若无目标则不寻路
    if (!_target.HasValue) { _pathDirection = direction; return direction; }
    Vector3Int goalCell = _grid.WorldToCell(_target.Value);

    bool found = PathProbe.TryFindStep(
        _grid.Geometry, selfCell, goalCell,
        c => _grid.HasCell(c) && !_grid.IsObstacle(c),
        _pathFrontier, _pathQueue, _pathVisited, _pathCameFrom,
        out Vector3Int step);

    if (found)
    {
        Vector2 stepCenter = _grid.Geometry.CellCenter(step);
        Vector2 toStep = stepCenter - Motor.Position;
        _pathDirection = toStep.sqrMagnitude > 0f ? toStep.normalized : direction;
    }
    else
    {
        _pathDirection = direction;   // 找不到就撞墙
    }

    return _pathDirection;
}
```

## 6.1 `AggroState`（新文件，Logic 层）

新建 `Assets/Scripts/Logic/Actor/AggroState.cs`：

```csharp
namespace DeepseaOil.Logic
{
    /// <summary>仇恨状态：视野内获得、维持距离内保持、超时丢失；不做视线遮挡，参数先用字段</summary>
    /// <remarks>参数搬表见阶段二；当前为硬编码默认值。</remarks>
    public sealed class AggroState
    {
        // 阶段二搬表：视野距离 / 维持距离 / 丢失延迟
        private const float VisionRange = 10f;
        private const float SustainRange = 14f;
        private const float LoseDelay = 3f;

        private bool _hasAggro;
        private float _lastSeenTime;

        public bool HasAggro => _hasAggro;

        /// <summary>每物理帧调一次；target 为 null 时保持当前状态不清（无目标的敌人不主动丢）</summary>
        public void Tick(Vector2 self, Vector2? target, float now)
        {
            if (!target.HasValue) return;

            float sqrDist = (target.Value - self).sqrMagnitude;

            if (sqrDist <= VisionRange * VisionRange)
            {
                _hasAggro = true;
                _lastSeenTime = now;
                return;
            }

            if (!_hasAggro) return;

            if (sqrDist <= SustainRange * SustainRange)
            {
                _lastSeenTime = now;
                return;
            }

            if (now - _lastSeenTime >= LoseDelay) _hasAggro = false;
        }

        /// <summary>强制清仇恨，白雾等效果调</summary>
        public void ForceLose() { _hasAggro = false; }
    }
```

## 6.6 二级反应：白雾清仇恨 / 超导向心吸引

**位置**：`TileChainReactor.CommitDuo`。

**判定条件**（阶段一硬编码，阶段二搬表）：

```csharp
// 白雾：产物空地 且 半径 > 1.5
if (duo.ResultTile == TileStateType.Normal && duo.EffectRadius > 1.5f)
{
    BreakAggroInRadius(grid, origin, duo.EffectRadius);
}

// 超导：产物结冰 且 半径 > 1.5
if (duo.ResultTile == TileStateType.Freeze && duo.EffectRadius > 1.5f)
{
    PullInRadius(grid, origin, duo.EffectRadius);
}
```

**`BreakAggroInRadius`**：遍历半径内格，用 `grid.Registry.TryGetIn(cell, out targets)`，对每个 `IEffectTarget` 若实现 `EnemyActor` → 调 `ForceLoseAggro()`。

**问题**：`TileChainReactor` 是 Logic 层，`EnemyActor` 是 Presentation 层，**跨层调用会编译不过**。

**解决方案**：加一个 Logic 层接口：

```csharp
namespace DeepseaOil.Logic.Combat
{
    /// <summary>可被清仇恨的目标</summary>
    public interface IAggroBreakable
    {
        void ForceLoseAggro();
    }
}
```

`EnemyActor` 实现它（`void IAggroBreakable.ForceLoseAggro() => ForceLoseAggro();`）。

`BreakAggroInRadius` 里：`if (target is IAggroBreakable b) b.ForceLoseAggro();`

**`PullInRadius`**：
```csharp
Vector2 center = grid.Geometry.CellCenter(origin);
foreach (cell in 半径内)
    foreach (target in registry.TryGetIn(cell))
        if (target is IKnockBackable kb && target is IAlivable a && a.IsAlive)
        {
            Vector2 toCenter = center - target.Position;
            if (toCenter.sqrMagnitude <= 0.001f) continue;
            kb.ApplyKnockback(toCenter.normalized * PullStrength);   // PullStrength 常量，阶段二搬表
        }
```

`PullStrength` 用常量 `5f`。

**注意**：`ApplyKnockback` 走的是 `_pendingKnockback` 挂起机制（`EnemyLogic.ApplyKnockback`），下个物理帧才生效。这是正确的。
