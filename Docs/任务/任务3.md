> # 八、`PopupDriver`（新增）
>
> 路径：`Presentation/Effects/Drivers/PopupDriver.cs`。构造签名 `internal PopupDriver(in EffectSpec spec, Transform root)`。
>
> **字段**：
>
> ```
> private sealed class PopupInstance {
>     public PopupView View;
>     public Vector2 StartPos;
>     public Color Tint;
>     public float Elapsed;
>     public float Duration;
>     public int HandleId;
> }
> private readonly Dictionary<int, PopupInstance> _active = new();  // 或 List，选一
> private readonly Pool<GameObject> _pool;
> private int _nextId;
> private int _epoch = 1;
> ```
>
> **契约**：
>
> | 项             | 值                                                           |
> | -------------- | ------------------------------------------------------------ |
> | `AssetKey`     | `effects/DamagePopup`                                        |
> | `IsAssetReady` | `_pool != null`                                              |
> | `IsSingleton`  | false                                                        |
> | 池             | `Pool<GameObject>`，`maxSize` 取 `spec.MaxSize`；`PoolOverflowPolicy.CreateOrDrop` |
>
> **`OnAssetLoaded(Object asset)`**：`asset as GameObject` → 建池 + `Prewarm(spec.Prewarm)`（结构参照 `ParticleDriver.BuildPool`）。
>
> **`Play(id, ctx)`**：
> - 池空 → `WarnPoolFull`（节流，参照 `ParticleDriver`）+ 返回 `None`
> - 借对象 → `GetComponent<PopupView>()`
> - 读一次 `ConfigModule.VisualFeel`（`popupRiseHeight` / `popupDuration` / `popupSortingOffset` / `popupRiseEase` / `popupFadeEase`）
> - 时长 = `ctx.Duration > 0 ? ctx.Duration : VisualFeel.popupDuration`
> - 位置 = `ctx.Position`；**不读 `ctx.Anchor`**（飘字不跟随）
> - 值 = `Mathf.RoundToInt(ctx.Value)`
> - 色 = `ctx.Tint`
> - `View.SetValue(value)` / `SetColor(tint)` / `SetAlpha(1)`
> - `renderer.sortingOrder = RenderOrder.ActorOrder(pos.y) + VisualFeel.popupSortingOffset`（若 prefab 根无 renderer，取第一个子 renderer）
> - 记 `PopupInstance`，返回 `EffectHandle`
>
> **`Tick(dt)`**：
> - 遍历 `_active`：`Elapsed += dt`；`t = Elapsed / Duration`
> - `t >= 1` → 归还池、摘账
> - `y = StartPos.y + VisualFeel.popupRiseHeight * (1 - pow(1 - t, riseEase))`
> - `alpha = 1 - pow(t, fadeEase)` → `View.SetAlpha(alpha)`
> - 位置写世界坐标（`transform.position = new Vector3(StartPos.x, y, 0f)`）
>
> **`Stop` / `CleanAll` / `Dispose`**：句柄校验 + 归还池 + 清状态。结构参照 `ParticleDriver`。
>
> **注释**：`/// <remarks>瞬态，不跟随 ctx.Anchor；位置在 Play 那一刻定死</remarks>`
>
