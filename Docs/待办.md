- `VisualPalette.EnemyBodyColor()`（`slowMultiplier < 1` 取 `enemyBodySlowed`）现在**零消费者**：减速色改由 `EnemyActor.ApplySlowTint` 直接读 `enemyBodySlowed` 发给驱动。留着是给"垫色该取哪一色"留一个纯函数入口，要删就删它，别删 `enemyBodyNormal`（死亡 `Shatter` 的碎片色还读它）。
- `PrimitiveSprites` 缺统一取件口 `Get(PrimitiveShape)`：现在是 `Circle` / `Square` / `GroundDiscOrRing` 几个静态成员各管一摊。

## 其它（改错了不报错，只表现成手感 / 观感错）

- `ConfigModule` 没有重置入口：重复 `Init` 抛异常且无 `Reset`，测试只能靠 `IsReady` 守卫跳过。
- `AssetModule.Preload` 用 `typeof(UnityEngine.Object)` 加载 ⇒ `TryGet<Sprite>` 是否命中取决于条目真实类型（属已知待验证项）。

- `UIMgr` 的 EventSystem 去重只在 `Init` 那一刻做一次：之后加载的场景若自带 `EventSystem`，Unity 的每帧警告会回来；同层面板顺序也无法控制（全仓无 `SetSiblingIndex`），由 `Canvas.prefab` 的兄弟顺序决定。

- **动画状态机的参数是硬契约，缺一个只刷 Console 不报错**：`ActorAnimationView.SetMotion` 每帧写 `Speed` / `MoveX` / `MoveY` / `FacingX` 四个 float，`TriggerHurt` / `TriggerDie` 写 `Hurt` / `Die` 两个 trigger，玩家侧还有 `IsDashing` / `TriggerThrow` / `TriggerPlant`；另有 `FadeAlpha` 一个 float，**由死亡剪辑自己用 `1 → 0` 的曲线驱动**（控制器里默认值填 `1`，代码只读它当尸体淡出的 alpha 源），且死亡剪辑**末帧**要挂一个调 `ActorAnimationView.OnDeathAnimationEnd` 的 AnimationEvent。控制器里少一个参数，Unity 只打一条 `Animator.SetFloat: Parameter 'Hash -xxx' does not exist.` 警告并按帧刷屏 —— 表现成"动画不动 + Console 999+"。`Enemy_1_AC.controller` 曾因 `m_AnimatorParameters: []` 整族缺失；新做/改控制器后请对照 `Presentation/Visual/AnimHashes.cs` 逐项补齐。**这后两项现在都还缺**：`Enemy_1_AC` / `Enemy_2_AC` 都没有 `FadeAlpha`，`Enemy_*_Die.anim` 的 `m_Events` 是空 ⇒ 有 Animator 的敌人死亡后等的是一个**永不到来的事件**，**不会被回收**（只有无 Animator 才走 `deathFallbackSeconds` 兜底计时）。- **沙盒场景的 `TileEffect` 排序档位与规范不符**：规范是 `Ground=0 / InitialSetup=1 / TileEffect=2`（**只有主场景 `Range.unity` 对**）；三个沙盒里 `TileEffect=1`，`Slice_GridReaction` 还与 `InitialSetup` 同档。当前不出问题（`InitialSetup` 读完就 `SetActive(false)`，效果层始终压在地板之上），但**同时显示两层时谁在上面由渲染顺序碰运气**。顺手改掉即可。
- **`SwitchTileState` 给每个新格分配一批闭包**：`GridLogic.RegisterStateFactories` 里 `machine.Register(id, () => _stateFactory(id))` 按 `tile_state` 行数（当前 16）分配闭包 + 委托，而它挂在 `OnBallHit` 这条 AGENTS.md 点名的热路径上。当前只在"某格第一次被切状态"时发生一次，不是每帧分配 ⇒ 现状可接受，但格数一多就是可观的瞬时 GC。要收口：把工厂表缓存成 `Dictionary<TileStateType, Func<ITileState>>`，或让 `TileStateMachine` 预置一张静态委托表。
